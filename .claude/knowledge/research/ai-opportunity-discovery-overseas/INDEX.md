## 질문

1. AI는 고객 데이터에서 좋은 사업·제품 아이디어를 어디까지 안정적으로 발견할 수 있는가?
2. 커뮤니티·후기 마이닝을 실제 기회 판단으로 연결하려면 어떤 검증 단계가 필요한가?
3. 해외 연구와 제품은 증거 추적성, 편향, 합성 사용자 문제를 어떻게 다루는가?
4. 모요 사례를 더 고도화하면 어떤 운영체계가 되는가?

## 판정 원칙

- 실제 고객 증거와 AI가 생성한 가설을 분리한다.
- 벤더의 제품 설명은 구현 방향의 증거로만 사용하고 성과 증명으로 취급하지 않는다.
- 커뮤니티 글은 실무 경험을 보여주는 보조 자료로 사용한다.
- 논문·공식 프레임워크·공개 코드처럼 원문을 확인할 수 있는 자료를 우선한다.
- 모든 AI 생성 인사이트는 원문 인용과 출처로 역추적할 수 있어야 한다.

## 수집 방법

- 웹 검색: Exa 공개 MCP를 `npx mcporter`로 직접 호출
- 웹 본문: Jina Reader
- GitHub: `gh` CLI
- Reddit: 인증된 `rdt-cli`
- PDF: World Bank 공식 PDF를 `pdftotext`로 확인

## 수집 제한

- Exa 공개 MCP는 초기 검색 후 무료 호출 한도 429가 발생해 이후 검색은 공식 페이지 직접 조회와 웹 검색으로 보완했다.
- ACM CollabCoder 본문은 보안 확인 화면으로 직접 수집하지 못해 최종 핵심 근거에서는 제외했다.
- Microsoft Research의 과거 논문 소개 URL은 현재 404여서 최종 핵심 근거에서는 제외했다.
- Reddit 인증은 유효했지만 쿠키 갱신 경고가 반복됐다. 기존 읽기 세션으로 수집한 결과만 사용했다.

## 신뢰도

이 리서치는 `researcher` 스킬의 L1 초안이다. 논문 결과는 해당 연구의 데이터와 조건 안에서 해석해야 하며, 제품 페이지의 자동화 성능 주장은 독립 검증되지 않았다.
