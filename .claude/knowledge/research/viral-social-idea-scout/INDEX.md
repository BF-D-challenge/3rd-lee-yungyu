## 질문

1. YouTube·X·Instagram의 바이럴 게시물을 제품 아이디어 원천으로 쓰는 제품은 매력적인가?
2. 현재 Idea Lab보다 나은 점과 약해지는 점은 무엇인가?
3. 독립 제품, 전면 피벗, 현재 앱의 상류 기능 중 어느 형태가 적합한가?

## 조사 방법

- 현재 앱: Idea Lab 생성 원리, 카드 흐름, 결과물, 외부 플랫폼 MVP 제한을 코드에서 확인
- YouTube: `yt-dlp` 공개 검색으로 outlier·viral idea 관련 실제 검색 결과 확인
- X: 인증된 `twitter-cli` 검색을 시도하고 실패 원인을 기록
- Instagram: Meta의 공식 Postman API 문서와 공개 제품 문서 확인
- 경쟁 제품: 각 제품의 공식 기능 페이지를 우선 확인

## 제한

- X 로그인 검증은 성공했지만 검색 요청은 CLI 최신 버전에서도 HTTP 404로 실패했다. X의 실제 게시물 표본 대신 공식 API 요금·검색 문서와 경쟁 제품의 공개 설명을 사용했다.
- Instagram의 대규모 공개 콘텐츠 탐색은 일반 Instagram API의 주 사용 범위가 아니다. 프로 계정·앱 심사·권한 제약을 전제로 판단했다.
- 경쟁사 페이지의 사용자 수, 데이터 규모, 성능 주장은 독립 검증하지 않았다.

## 신뢰도

`researcher` 스킬의 L1 초안이다. 제품 방향 판정에는 충분하지만, 실제 전환·지불 의향은 수동 MVP로 별도 검증해야 한다.
