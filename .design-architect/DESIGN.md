# 맛핀 Design Contract

## 공통 Design Read

화면 유형: Instagram DM에서 시작해 개인 웹 보관함으로 이어지는 소비자 서비스와, 대화 문제를 한 화면에서 복구하는 운영 CRM

대상 사용자: 저장한 장소를 역으로 다시 찾는 Instagram 사용자, 최근 대화와 처리 실패를 관리하는 맛핀 운영자

시각 언어: 검정에 가까운 배경, 불투명한 짙은 표면, 밝은 한글 본문, 저장과 행동을 구분하는 코랄 계열 강조색을 사용합니다.

기억 단서: `matpin.kr` 워드마크, Instagram 게시물, 역 이름, 개인 보관함, 한 사람의 대화와 처리 상태

공통 원칙: 입력과 결과의 인과를 먼저 보여주고, 기술 이름보다 사용자가 얻은 장소와 다음 행동을 앞에 둬요.

## 사용자 화면 Design Read

목적: 공개 게시물을 보내는 방법을 이해하고, DM에서 받은 개인 링크로 저장 장소를 빠르게 다시 찾습니다.

진입 상태: 사용자는 Instagram에서 저장할 장소 게시물을 발견했거나, 저장 완료 DM을 받은 상태예요.

인지 순서:

1. 게시물을 보내면 가까운 역별로 정리된다는 약속
2. `matpin.kr`로 보내는 실제 세 단계
3. 장소를 확인하는 근거와 개인정보 원칙
4. 개인 보관함의 역 검색과 게시물 카드
5. 원본 게시물, 길찾기, 삭제 행동

주 CTA: `Instagram에서 시작하기`, 역 또는 게시물 카드, `게시물 보내기`

이탈 감정: 위치를 추적하거나 다른 사람의 보관함과 섞이지 않는다는 확신이 필요합니다.

### 사용자 화면 다이얼

- DESIGN_VARIANCE: 4 / 10
- MOTION_INTENSITY: 2 / 10
- VISUAL_DENSITY: 6 / 10

랜딩은 실제 사용 장면과 저장 전후를 충분히 설명하되, CTA는 한 번에 하나만 강하게 보여줘요. 보관함은 역과 게시물 수가 늘어나도 검색, 역 묶음, 카드의 같은 문법을 반복합니다.

### 사용자 화면 토큰

- 기본 배경: `#0b0b0d` 또는 더 어두운 `#08090b`
- 기본 표면: `#141518`에서 `#1d1f23`
- 본문: `#f5f5f3`에서 `#faf7f2`
- 보조 본문: `#9a9ca3`에서 `#b8b0aa`
- 핵심 강조: 코랄 `#f16055`, 주황 `#ff6b35`
- 성공: `#79d7a4`
- 구분선: 흰색 10%에서 20%
- 글꼴: 프로젝트 한글 sans와 시스템 sans fallback
- 제목: 820에서 880 굵기, 짧은 줄, 촘촘한 자간
- 본문: 최소 1.5 줄간격, 긴 개인정보 문장은 1.7 이상
- 기본 간격: 4px 배수, 주요 구획은 24px 이상
- 행동 영역: 최소 44px

## 사용자 화면별 계약

### `/matpin` 소개 화면

- 첫 화면은 `맛집 게시물을 역별로 모아드려요`라는 결과 약속과 `Instagram에서 시작하기` 행동을 함께 둡니다.
- 대표 장면은 Instagram 공유 화면에서 `matpin.kr`을 선택하는 상황과 저장 결과를 순서대로 설명해요.
- 저장 전후, 공유 방법, 장소 근거 확인 순서, 계정별 보관함, FAQ 순으로 내려갑니다.
- 데스크톱은 약속과 대표 이미지를 2열로 배치하고, 840px 미만에서는 1열로 전환해요.
- 600px 미만에서는 핵심 Instagram CTA를 하단에서 다시 제공하되 본문을 가리지 않습니다.
- 근거 없는 정확도, 가짜 저장 수, 자동화 과장과 위치 추적처럼 보이는 지도를 사용하지 않습니다.

### `/matpin/saved#token=...` 개인 보관함

- 상단에는 홈 복귀, 워드마크, 새 게시물 보내기만 둡니다.
- `저장한 역`, 역 수, 게시물 수를 먼저 보여주고 바로 아래에 역 이름 또는 가게 검색을 배치해요.
- 역 이름을 구획 제목으로 쓰고, 관련 게시물은 세로 비율의 카드 레일로 보여줍니다.
- 한 게시물에 여러 장소가 있어도 게시물의 정체성을 유지하고 상세에서 장소 목록을 확인합니다.
- 장소 상세에는 원본 Instagram 게시물과 길찾기처럼 실제 연결된 행동만 제공해요.
- 보관함 전체에 개인정보 마스킹을 적용하고 현재 위치를 사용하지 않는다는 설명을 유지합니다.
- 빈 상태는 첫 게시물을 보내는 방법으로 연결하고, 검색 결과 없음은 검색어 초기화 행동을 제공합니다.
- 로딩은 `역별 보관함을 열고 있어요`, 오류는 최신 개인 링크 사용 방법을 함께 보여줘요.

### `/matpin/delete#token=...` 데이터 관리

- 삭제 범위인 저장 장소, 게시물 처리 기록, 개인 보관함 연결 정보를 행동 전에 설명합니다.
- 첫 버튼은 삭제 의도를 시작하고, 두 번째 확인에서만 실제 전체 삭제를 실행해요.
- 위험 행동은 일반 CTA와 색과 문구를 분리하며 취소를 같은 화면에 둡니다.
- 성공하면 URL의 개인 토큰을 즉시 제거하고 복구할 수 없음을 명확히 표시해요.
- 실패하면 확인 상태와 재시도 행동을 보존합니다.

## 관리자 CRM Design Read

목적: 운영 담당자가 답장 필요, 처리 지연과 실패를 발견하고 대화 맥락을 잃지 않은 채 한 화면에서 복구합니다.

진입 상태: 승인된 Google 계정으로 최근 Instagram 대화와 맛핀 처리 상태를 확인하려는 상황이에요.

인지 순서:

1. Instagram 실시간 조회 가능 여부와 기간별 운영 지표
2. 조치가 필요한 대화 목록과 필터
3. 선택한 대화의 최근 메시지와 처리 상태
4. 사용자별 저장 장소와 사용량 맥락
5. 개별 답장, 실패 재처리, 보관함 링크 재전송

주 CTA: 조치가 필요한 대화 선택, 수신자와 문구를 확인한 개별 답장, 조건이 충족된 복구 행동

기억 단서: 검은 운영 작업대 위에서 대화, 처리 결과, 사용자 맥락이 나란히 이어지는 3열 구조

### 관리자 다이얼

- DESIGN_VARIANCE: 3 / 10
- MOTION_INTENSITY: 1 / 10
- VISUAL_DENSITY: 8 / 10

운영 도구이므로 익숙한 목록과 상세 구조를 유지합니다. 정보량은 높지만 장식이 아니라 상태, 시각, 장소 수, 사용량과 복구 행동에만 밀도를 사용해요.

### 관리자 시각 토큰

- 배경: `#090a0b`
- 패널: `#101214`
- 보조 패널: `#15181b`
- 구분선: `#292d31`
- 본문: `#f4f4f2`
- 보조 본문: `#979da3`
- 핵심 강조: `#ff5364`
- 성공: `#66d49b`
- 주의: `#efb65b`
- 표면은 불투명하게 유지하고 글래스 효과를 사용하지 않습니다.
- 장식용 그라데이션, 과도한 그림자와 목적 없는 큰 차트는 제외해요.
- 숫자는 tabular 숫자로 정렬해 변화와 비교가 흔들리지 않게 합니다.

## 관리자 레이아웃 계약

### 데스크톱

- 상단 64px 바에는 브랜드, 승인 이메일, 새로고침과 로그아웃을 둡니다.
- 그 아래에 기간 선택과 최근 대화, 답장 필요, 처리 중, 실패, 저장 장소, 캐시 적중, API 요청과 토큰 지표를 한 줄로 배치해요.
- 작업 영역은 대화 목록 280px에서 340px, 선택 대화 최소 440px, 사용자 맥락 280px에서 330px의 3열입니다.
- 목록 선택이 바뀌어도 중앙 대화와 우측 맥락만 갱신하고 상단 지표와 필터 위치는 고정합니다.
- 1120px 미만에서는 사용자 맥락을 오른쪽 시트로 전환해 대화 폭을 지켜요.

### 모바일

- 760px 이하에서는 대화 목록과 선택 대화를 한 화면씩 전환합니다.
- 대화에서 뒤로 가면 현재 필터와 목록 위치를 보존해요.
- 사용자 맥락은 최대 화면 폭 92%의 오른쪽 시트로 열고 스크림과 닫기 행동을 제공합니다.
- 지표는 가로 스크롤로 유지해 숫자를 지나치게 축소하지 않습니다.
- 하단 답장 영역은 안전 영역을 고려하며, 대화 본문을 가리지 않아요.

## 관리자 컴포넌트 계약

### 운영 지표

- 기간은 24시간, 7일, 30일, 전체 중 하나를 선택합니다.
- Meta 대화 조회 성공 시 `Instagram 실시간`, 실패 시 `DB 지표만 표시`를 명시해요.
- 차트 대신 현재 수치와 상태만 보여 대화를 가리지 않습니다.
- 캐시 적중은 적중 수와 준비된 캐시 수를 함께 표시해 비용 맥락을 제공합니다.

### 대화 목록

- 필터는 전체, 답장 필요, 처리 중, 저장 완료, 실패로 고정합니다.
- 각 행은 프로필, 이름 또는 사용자명, 최근 메시지, 경과 시각, 저장 처리 상태를 보여줘요.
- 최신 사용자 메시지가 마지막이면 답장 필요로 표시합니다.
- 위아래 화살표로 이전과 다음 대화를 선택하고 선택된 행의 포커스를 유지해요.
- 일부 대화만 불러온 경우 목록 위에 부분 상태를 표시하며 성공한 결과를 숨기지 않습니다.

### 선택 대화

- 최근 메시지는 최대 20건임을 헤더에 밝힙니다.
- 발신과 수신 방향, 시각, 텍스트와 첨부 종류를 구분해요.
- 처리 중, 저장 완료, 실패와 삭제 상태는 메시지 옆의 배지와 처리 카드로 연결합니다.
- 직접 보낸 글, 이미지와 동영상은 대화 맥락에는 보이지만 저장 게시물처럼 표시하지 않습니다.
- 로딩, 빈 상태와 Meta 오류를 중앙 패널 안에서 구분해요.

### 사용자 맥락

- Meta에서 실시간으로 읽은 이름, 사용자명과 프로필 이미지를 먼저 둡니다.
- 저장 장소 수와 장소 이름, 최근 처리 상태, 분석 시간과 토큰을 이어서 보여줘요.
- scoped ID, 개인 토큰, 암호문과 임시 미디어 URL은 표시하지 않습니다.
- 프로필 일부를 불러오지 못해도 저장 장소와 처리 정보는 유지해요.

### 답장과 복구 행동

- 자유 문구 답장은 최근 사용자 메시지 후 24시간 미만일 때만 활성화합니다.
- 답장 확인 대화상자는 수신자, 최신 사용자 메시지, UTF-8 기준 1,000바이트 이하 최종 문구를 한 번에 보여줘요.
- 취소와 발송은 명확히 분리하고 발송 중에는 중복 행동을 잠급니다.
- 실패 재처리는 실패한 게시물 처리 카드에만 제공합니다.
- 보관함 링크 재전송은 저장 장소가 있는 사용자에게만 노출해요.
- DM 발송은 수신자와 최종 문구 확인 대화상자를 거칩니다. 링크 재전송은 수신자를 확인하고, 재처리는 실패 상태인 한 건에서만 실행하며 성공 뒤 목록과 지표를 갱신해요.

## 상태와 오류 UX

- 미로그인: 승인된 Google 계정으로 로그인하는 행동 하나를 보여줍니다.
- 허용목록 미설정: 운영 접근이 잠겼다는 사실과 필요한 환경 변수 이름을 알려줘요.
- 미허용 계정: 현재 계정에 권한이 없음을 설명하고 다른 계정으로 로그인할 수 있게 합니다.
- 전체 로딩: 각 패널의 크기를 유지하며 로딩 문구와 작은 상태 아이콘을 사용해요.
- 빈 목록: 현재 필터에 해당하는 대화가 없다는 이유와 필터 변경 행동을 제공합니다.
- 부분 응답: 일부 Meta 대화를 읽지 못했지만 보이는 정보는 사용할 수 있음을 명시합니다.
- 전체 오류: 운영자가 이해할 수 있는 원인 문구, 현재 선택 보존, 새로고침 행동을 함께 제공해요.
- 행동 오류: 24시간 만료, 재처리 불가, 저장 장소 없음, Meta 전송 실패를 서로 다른 문구로 구분합니다.
- 성공: 별도 축하 화면으로 흐름을 끊지 않고 대화와 지표의 갱신된 상태로 확인합니다.

## 접근성

- 모든 버튼, 링크, 입력과 목록 행의 행동 영역은 최소 44px입니다.
- `focus-visible`은 어두운 배경에서 현재 키보드 위치를 알아볼 수 있는 윤곽선으로 표시해요.
- 대화 목록은 Tab과 위아래 화살표로 이동하고, Enter 또는 Space의 기본 버튼 동작을 유지합니다.
- 확인 대화상자는 초점을 내부에 가두고 제목, 설명, 닫기 행동과 Escape 복귀를 제공합니다.
- 모바일 맥락 시트는 닫기 버튼과 스크림으로 원래 대화 화면에 복귀할 수 있습니다.
- 아이콘 버튼은 보이는 문구가 없으면 접근 가능한 이름을 제공합니다.
- 색만으로 저장, 실패와 처리 상태를 구분하지 않고 텍스트 배지를 함께 사용해요.
- 입력 오류와 전역 오류는 `role="alert"` 또는 같은 수준의 즉시 안내로 전달합니다.

## 모션과 성능

- 버튼 피드백과 시트 전환만 160ms 안팎으로 사용합니다.
- 대화 선택, 필터 변경과 지표 갱신에는 장식 애니메이션을 넣지 않아요.
- `prefers-reduced-motion`에서는 시트 전환을 제거하고 로딩 회전을 느리게 하거나 정적 상태로 대체합니다.
- 프로필 이미지와 메시지 미리보기는 Meta 응답 범위만 사용하고 불필요한 선조회는 피합니다.
- 긴 대화 목록과 지표는 패널 내부에서만 스크롤해 전체 레이아웃 이동을 줄여요.

## 금지할 기본값

- DM 자동 대량 발송처럼 보이는 선택 체크박스와 일괄 행동
- 사용자 삭제와 장소 수정처럼 실제로 연결되지 않은 관리자 버튼
- 개인 scoped ID, 보관함 토큰, 암호문과 임시 미디어 URL 노출
- 실제 수치가 아닌 예시 지표, 가짜 대화와 데모 로그인
- 운영 밀도를 가리는 글래스 표면, 장식 그라데이션, 큰 면적의 빈 차트
- 실패 원인을 숨긴 `문제가 발생했습니다` 단독 문구
- 24시간 발송 제한을 우회하거나 수신자 확인 없이 보내는 행동
- 직접 첨부한 이미지와 동영상을 저장 완료처럼 보여주는 상태
