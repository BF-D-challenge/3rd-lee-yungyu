# 맛핀 Experience Contract

플랫폼: Instagram DM과 responsive web

전체 사용자 여정: 공개 장소 게시물 발견 → `matpin.kr`에 공유 → 접수 답장 → 장소 분석 또는 영구 캐시 사용 → 역별 저장 → 짧은 개인 링크 수신 → 보관함에서 다시 찾기 또는 삭제

전체 관리자 여정: Google 로그인 → 운영 지표 확인 → 대화 선택 → Meta 실시간 대화와 DB 처리 맥락 확인 → 한 사람에게 답장 또는 실패 복구 → 감사 기록과 갱신된 상태 확인

## 사용자 여정

| 단계 | 진입 조건 | 사용자의 질문 | 주 행동 | 실제 결과 | 실패와 회복 |
|---|---|---|---|---|---|
| 1. 발견 | 공개 Instagram 장소 게시물을 보고 있음 | 나중에 이 장소를 어떻게 찾지 | 공유 버튼에서 `matpin.kr` 선택 | 지원 게시물 이벤트가 Meta Webhook으로 전달됩니다. | 비공개 또는 접근할 수 없는 게시물은 우회하지 않고 다른 공개 게시물을 요청 |
| 2. 접수 | 서명이 검증된 공유 이벤트 수신 | 제대로 보냈나 | 접수 답장 확인 | 릴스 또는 게시물 수신과 처리 시작을 알려줘요. | 동일 게시물이면 다시 분석하지 않고 저장 내역을 확인 중이라고 안내 |
| 3. 분류 | DM 이벤트 해석 | 이 입력도 저장되나 | 안내 확인 | 공개 릴스, 피드, 캐러셀과 개별 게시물 링크만 처리합니다. | 직접 작성한 글, 직접 첨부한 이미지와 동영상, 프로필, 외부 링크는 저장하지 않고 올바른 공유 방법을 답장 |
| 4. 분석 | 지원 게시물과 미디어 식별자 확보 | 어느 장소인가 | 기다림 | 영구 캐시가 있으면 즉시 재사용하고, 없으면 게시물 근거를 분석해 장소 단서를 추출해요. | 일시 실패는 제한된 재시도, 최종 실패는 원인에 맞는 안내와 다른 공개 게시물 요청 |
| 5. 장소 확인 | 장소 단서 존재 | 실제 장소가 맞나 | 자동 처리 | 지도 근거가 있는 후보만 확정하고 한 게시물의 여러 장소를 모두 저장합니다. | 장소 근거가 없으면 아무 장소도 저장하지 않았다고 명시 |
| 6. 완료 답장 | 장소 저장 성공 | 어디서 볼 수 있나 | 짧은 링크 열기 | 저장 장소 수와 `/s/{code}` 개인 보관함 링크를 DM으로 보내요. 링크는 마지막 지원 게시물 수신 뒤 90일 동안 유효하고 새 게시물 수신 때 갱신합니다. | 답장 전송 실패는 처리 상태에 남겨 운영자가 확인하고 링크를 재전송 |
| 7. 보관함 | `/s/{code}` 진입 | 어느 역에서 갈 수 있나 | 역 또는 장소 선택 | 서버가 개인 토큰을 fragment에 둔 `/matpin/saved#token=...`로 연결하고 역별 저장 장소를 표시합니다. | 만료되거나 잘못된 링크는 Instagram에서 받은 최신 링크 사용을 안내 |
| 8. 재사용 | 장소 상세 확인 | 원본과 길찾기는 어디 있나 | 원본 게시물 또는 길찾기 열기 | 저장 근거로 돌아가거나 지도에서 이동 경로를 확인해요. | 외부 앱을 열 수 없으면 보관함 상태를 유지 |
| 9. 삭제 | 더 이상 저장할 필요가 없음 | 내 데이터를 지울 수 있나 | 장소 삭제 또는 데이터 관리 진입 | 장소 한 곳을 삭제하거나 `/matpin/delete#token=...`에서 전체 데이터를 삭제합니다. | 전체 삭제는 확인을 한 번 더 받고, 실패하면 토큰과 현재 화면을 유지한 채 재시도 |

## 같은 게시물을 다시 보냈을 때

1. 미디어 식별자로 완료된 분석 캐시를 조회합니다.
2. 유효한 캐시가 있으면 AI와 지도 분석 요청을 만들지 않아요.
3. 캐시의 장소 결과를 현재 사용자의 보관함에 적용합니다.
4. 같은 사용자에게 이미 저장된 장소는 중복 생성하지 않습니다.
5. 완료 답장에는 기존 게시물이라는 점과 현재 보관함 장소 수를 알려줘요.

## 지원하지 않는 입력의 안내 계약

| 입력 | 저장 또는 분석 | 답장 핵심 | 다음 행동 |
|---|---|---|---|
| 직접 작성한 글 | 하지 않음 | 글은 저장하지 않았습니다. | 장소가 나온 개별 게시물의 공유 버튼 사용 |
| 직접 첨부한 이미지 | 하지 않음 | 사진은 받았지만 저장하지 않았어요. | 사진의 원본 Instagram 장소 게시물 공유 |
| 직접 첨부한 동영상 | 하지 않음 | 동영상은 받았지만 저장하지 않았습니다. | 원본 릴스나 게시물 공유 |
| 외부 사이트 링크 | 하지 않음 | 이 링크는 저장하지 않았어요. | Instagram 장소 게시물 링크 전송 |
| Instagram 프로필 | 하지 않음 | 프로필은 저장하지 않았습니다. | 개별 릴스나 게시물 전송 |
| 지원하지 않는 첨부 | 하지 않음 | 보내준 항목은 저장하지 않았어요. | 공개 맛집, 카페 또는 여행지 게시물 공유 |

직접 DM 원문은 이 분류와 안내에만 사용하며 맛핀 DB나 AI 분석 입력에 전달하지 않습니다.

## 개인 보관함 인터랙션 계약

| 표시 이름 | 종류 | 실제 행동과 경로 | 성공 | 실패 또는 취소 |
|---|---|---|---|---|
| 짧은 보관함 링크 | 링크 | `/s/{code}`에서 개인 토큰 fragment가 있는 보관함으로 이동 | 역별 저장 장소 표시 | 유효하지 않으면 최신 DM 링크 요청 안내 |
| 역 선택 | 탐색 | 선택한 역의 저장 장소로 목록 좁힘 | 관련 장소와 원본 미디어 표시 | 다른 역 선택으로 즉시 복귀 |
| 원본 게시물 | 외부 링크 | 저장 근거 Instagram 게시물 열기 | 원본 맥락 확인 | 보관함은 유지 |
| 길찾기 | 외부 링크 | 검증한 장소의 지도 열기 | 지도에서 경로 확인 | 보관함은 유지 |
| 장소 삭제 | 쓰기 | 현재 장소 한 곳 삭제 | 목록과 개수 갱신 | 실패 문구 뒤 같은 장소에서 재시도 |
| 내 데이터 관리 | 이동 | 개인 토큰을 유지한 채 `/matpin/delete`로 이동 | 전체 삭제 범위 확인 | 뒤로 가기로 보관함 복귀 |
| 모든 데이터 삭제 | 파괴적 쓰기 | 확인 뒤 저장 장소, 처리 기록, 계정 연결 정보 삭제 | 토큰을 URL에서 제거하고 완료 상태 표시 | 실패하면 확인 상태와 재시도 행동 유지 |

## 관리자 CRM 여정

| 단계 | 진입 조건 | 운영자의 질문 | 주 행동 | 실제 결과 | 실패와 회복 |
|---|---|---|---|---|---|
| 1. 접근 | `/matpin/admin` 진입 | 누가 볼 수 있나 | Google 로그인 | 확인된 이메일이 `MATPIN_ADMIN_EMAILS`에 있으면 운영 화면을 엽니다. | 미로그인은 로그인 안내, 미허용 계정은 거부, 허용목록 미설정은 전체 잠금 |
| 2. 상황 파악 | 인증 성공 | 지금 문제가 있나 | 기간과 지표 확인 | 24시간, 7일, 30일, 전체 기준 대화와 처리 지표를 보여줘요. | Meta 조회가 실패해도 DB 지표는 유지하고 실시간 지표 미확인을 표시 |

## 관리자 화면 구조

- 데스크톱은 상단 운영 지표 아래에 대화 목록, 선택한 대화, 사용자 맥락의 3열을 유지합니다.
- 모바일은 목록과 대화를 한 화면씩 전환하고 사용자 맥락은 시트로 열어요.
- 대화 목록은 방향, 시각, 최신 처리 상태와 답장 필요 여부를 함께 보여줍니다.
- 대화 본문은 Meta에서 읽은 원문을 표시하지만 브라우저 응답 이후 맛핀 DB에 복제하지 않습니다.
- 사용자 맥락은 Instagram 프로필, 저장 장소, 처리 상태, 분석 시간과 토큰만 제공합니다.

|---|---|---|---|
| loading | 보관함을 불러오는 중임을 표시 | 지표, 목록, 상세 영역별 로딩 표시 | 완료까지 행동 잠금 |
| empty | 아직 저장한 장소가 없음을 설명 | 대화 또는 처리 이력이 없음을 설명 | 새 게시물 공유 또는 필터 초기화 |
| partial | 해당 없음 | 일부 Meta 대화를 읽지 못했다고 표시하고 성공한 결과 유지 | 새로고침 |
| error | 저장, 조회, 삭제 실패를 화면 안에서 설명 | Meta 조회 또는 행동 실패 이유를 운영 문구로 변환 | 입력과 선택을 유지하고 재시도 |
| permission | 개인 토큰이 없거나 유효하지 않음을 안내 | 미로그인, 허용되지 않은 계정, 허용목록 미설정 상태를 구분 | 최신 개인 링크 사용 또는 승인 계정 로그인 |
| processing | 접수 답장 뒤 완료 답장을 기다림 | 접수됨과 처리 중 상태를 구분 | 자동 처리 또는 운영자 새로고침 |
| success | 저장 장소 수와 개인 링크 표시 | 행동 성공 뒤 지표와 대화 갱신 | 다음 게시물 저장 또는 다음 대화 처리 |

## API와 보안 경계

- 사용자 저장, 조회, 장소 삭제와 전체 삭제는 개인 Bearer 토큰으로 보호합니다.
- 관리자 API는 Supabase `auth.getUser()`와 확인된 Google 이메일 허용목록을 매 요청 검증해요.
- 관리자 응답은 모두 `private, no-store`이며 서비스 역할 키, Instagram scoped ID, 암호문과 임시 미디어 URL을 브라우저에 보내지 않습니다.
- `/matpin/admin`과 하위 경로에서는 Google Analytics, Clarity와 Meta Pixel을 로드하지 않습니다.
- 자유 문구는 비어 있지 않은 UTF-8 기준 1,000바이트 이하로 제한하고 발송 직전 최근 사용자 메시지와 24시간 창을 다시 계산합니다.
- 자유 문구, 실패 재처리와 링크 재전송은 관리자별 idempotency key로 중복 실행을 막아요.
- 감사 로그는 행동의 증명에 필요한 해시와 메타데이터만 저장하고 DM 본문은 저장하지 않습니다.
