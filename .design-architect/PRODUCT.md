# 맛핀 Product Contract

제품명: 맛핀(Matpin)

한 줄 설명: Instagram에서 발견한 장소 게시물을 `matpin.kr`에 보내면 실제 장소를 찾아 가까운 역별 개인 보관함에 저장합니다.

주 사용자: Instagram에서 맛집, 카페, 여행지 게시물을 저장하고 나중에 지역이나 역으로 다시 찾는 사용자

locale: ko-KR

## 사용자 문제

- Instagram에 저장한 게시물이 쌓일수록 어느 동네의 어떤 장소인지 다시 찾기 어렵습니다.
- 릴스 한 개에 여러 장소가 등장하면 장소 이름을 따로 적고 지도에서 다시 검색해야 해요.
- 같은 게시물을 여러 번 보내거나 여러 사용자가 공유할 때마다 AI 분석 비용이 반복될 수 있습니다.

## 핵심 약속

- 사용자가 넣는 것: `matpin.kr` Instagram 계정으로 공유한 공개 릴스, 피드 게시물, 캐러셀 또는 해당 Instagram 게시물 링크
- 제품이 돌려주는 것: 게시물에서 확인한 실제 장소 전체, 가까운 역 분류, 짧은 개인 보관함 링크
- 첫 가치 순간: DM 답장에 있는 개인 링크를 열자 공유한 장소가 역별 보관함에 저장된 순간입니다.
- 주 행동: 저장할 공개 장소 게시물의 공유 버튼에서 `matpin.kr`을 수신자로 선택해요.
- 다음 행동: 보관함에서 역을 고르고 원본 게시물이나 길찾기를 엽니다.

## 지원 범위

- 공개 Instagram 릴스, 피드 게시물, 캐러셀과 개별 게시물 링크를 처리합니다.
- 한 게시물에서 근거가 확인된 장소가 여러 곳이면 모두 저장해요.
- 동일 게시물의 완료된 분석 결과는 TTL 없이 영구 캐시에 보관합니다. 같은 게시물은 다시 AI로 분석하지 않고 캐시 결과를 사용하며, 운영자가 실패 재처리를 명시적으로 실행한 경우에만 해당 결과를 무효화할 수 있습니다.
- 동일 사용자의 같은 게시물과 같은 장소는 중복 항목으로 늘리지 않습니다.
- 개인 보관함 링크는 짧은 `/s/{code}` 주소로 전달하고, 서버에서 개인 토큰이 URL fragment에 있는 보관함으로 연결합니다.
- 개인 보관함 링크는 마지막 지원 게시물 수신 뒤 90일 동안 유효하며, 새 게시물을 보내면 같은 계정의 유효 기간을 갱신해요.
- 사용자는 보관함에서 장소 한 곳을 삭제할 수 있으며, 데이터 관리 화면에서 계정 연결 정보와 저장 데이터를 모두 삭제할 수 있어요.

## 처리하지 않는 입력

- DM 입력창에 직접 작성한 글은 장소 분석이나 영구 저장 대상이 아닙니다.
- DM에 직접 첨부한 이미지와 동영상도 분석하거나 저장하지 않아요.
- Instagram 프로필, 외부 사이트 링크, 지원하지 않는 첨부 파일은 장소로 저장하지 않습니다.
- 처리하지 않는 입력에는 이유와 올바른 공유 방법을 같은 대화에서 안내해요.
- 비공개 게시물의 접근 제한을 우회하지 않으며, 지도 근거가 없는 장소를 확정하지 않습니다.

## 개인정보와 데이터 계약

- Instagram 발신자 식별자는 해시와 암호화된 값으로만 다룹니다.
- 임시 미디어 URL은 분석 중에만 사용하고 완료 또는 최종 실패 뒤 제거해요.
- 개인 보관함 토큰은 URL fragment로 전달해 서버 요청 로그와 외부 리퍼러에 남기지 않습니다.
- 이름, 사용자명, 프로필 이미지와 최근 DM 원문은 운영 화면에서 Meta API로 실시간 조회하며 맛핀 DB에 복제하지 않아요.
- 직접 보낸 글, 이미지, 동영상 원문은 DB에 저장하거나 AI 분석에 전달하지 않습니다.
- 완료된 미디어 캐시에는 게시물 식별자와 장소 분석 결과 및 사용량 정보만 저장하며 Instagram 발신자와 연결하지 않습니다.

## 운영 CRM 계약

- 운영자는 `/matpin/admin`에서 최근 Instagram 대화와 맛핀 처리 상태를 함께 확인합니다.
- 최근 DM 원문과 프로필은 Meta API에서만 읽고, 지원 게시물의 처리 상태와 저장 장소 및 사용량은 맛핀 DB에서 읽어요.
- 대화 상세는 Meta가 제공하는 최근 메시지 최대 20건까지만 표시합니다.
- 운영자는 마지막 사용자 수신 후 24시간 미만인 한 사람에게만 비어 있지 않은 UTF-8 기준 1,000바이트 이하의 자유 문구를 보낼 수 있습니다.
- 자유 문구 DM은 수신자와 최종 문구를 확인한 뒤 발송하며, 전송 직전에 수신자와 최근 사용자 메시지를 서버에서 다시 검증해요.
- 실패한 지원 게시물만 재처리할 수 있고, 저장 장소가 있는 사용자에게만 보관함 링크를 재전송합니다.
- 관리자 행동 로그에는 관리자 ID, 발신자 해시, 행동 종류, 문구 길이와 SHA-256, Meta 메시지 ID, 성공 또는 실패만 남깁니다. DM 원문은 저장하지 않아요.
- Google 로그인과 `MATPIN_ADMIN_EMAILS` 허용목록으로 접근을 제한합니다. 허용목록이 비어 있으면 모든 접근을 거부하며 데모 로그인을 제공하지 않습니다.

## 성공과 안전

- primary metric: 지원 게시물 수신 뒤 실제 장소가 저장되고 사용자가 개인 보관함을 다시 연 수
- cost metric: 영구 캐시 적중으로 생략한 AI 재분석 수와 토큰 절감량
- operation metric: 답장 필요, 처리 중, 실패 상태를 운영자가 한 화면에서 확인하고 복구한 수
- guardrail: 사용자 간 저장 데이터 혼합 0건, 직접 DM 원문 저장 0건, 지도 근거 없는 장소 저장 0건입니다.
- guardrail: 24시간 창 밖 자유 문구 발송 0건, 대량 발송 0건, 수신자 재검증 없는 발송 0건을 유지해요.

## 현재 범위 밖

- Instagram 저장함 전체 가져오기
- 사용자 위치 권한을 이용한 현재 위치 추적
- 관리자 대량 DM, 예약 발송, 첨부파일 발송과 자동 캠페인
- 관리자 화면에서 사용자 삭제 또는 장소 수정
- 친구 목록, 팔로우, 보상형 추천과 공개 피드
- 근거 없는 정확도, 처리 속도 또는 절감액 보장

## 제품 목소리

- 사용자가 무엇을 보냈고 어떤 결과가 생겼는지 먼저 말합니다.
- 실패 문구는 원인, 저장 여부, 다음 행동을 한 번에 알려줘요.
- 자주 쓰는 말: 게시물, 장소, 역별 보관함, 저장했습니다, 다시 보내주세요
- 쓰지 않는 말: 무조건, 완벽하게, 정확도 100%, 위치를 추적해요, 자동으로 다 됩니다
- 첫 인사 예시: 안녕하세요. 맛핀입니다. 저장하고 싶은 공개 맛집, 카페 또는 여행지 게시물을 공유 버튼으로 보내주세요.
