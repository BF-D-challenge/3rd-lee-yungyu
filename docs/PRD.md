# 맛핀 제품 요구사항

> 상태: 활성 정본
>
> 기준일: 2026-08-09

## 1. 제품 한 줄 설명

맛핀은 사용자가 Instagram에서 공유한 공개 장소 게시물을 분석해 실제 장소를 찾고, 개인 보관함에 가까운 역별로 저장한 뒤 DM으로 결과 링크를 보내는 서비스입니다.

## 2. 해결할 문제

Instagram에서 발견한 맛집, 카페, 여행지는 저장해도 다시 찾기 어렵습니다. 게시물마다 장소 이름과 주소 표기가 다르고, 여러 장소가 한 릴스나 캐러셀에 섞여 있기도 해요.

맛핀은 사용자가 하던 공유 행동을 그대로 사용합니다. 게시물을 `matpin.kr` 계정에 보내면 장소 분석, 지도 확인, 분류, 보관함 저장까지 이어집니다.

## 3. 핵심 사용자

- Instagram에서 장소를 자주 발견하고 저장하는 사람
- 저장한 게시물을 실제 약속이나 방문 전에 다시 찾는 사람
- 릴스 한 편이나 캐러셀 하나에 나온 여러 장소를 한 번에 정리하고 싶은 사람

핵심 작업은 “나중에 갈 장소 게시물을 보내고, 다시 찾기 쉬운 보관함으로 받는다”입니다.

## 4. 입력 계약

### 지원하는 입력

다음 입력은 공개 상태이고 Instagram의 개별 미디어 주소로 확인할 수 있을 때 처리합니다.

- Instagram 공유 기능으로 보낸 공개 릴스
- Instagram 공유 기능으로 보낸 공개 피드 게시물
- 여러 장으로 구성된 공개 캐러셀
- DM 본문에 붙여 보낸 공개 릴스 또는 개별 게시물 링크

캐러셀은 캡션과 확인 가능한 미디어를 함께 분석해 최대 3곳의 장소 후보를 저장합니다. 비공개, 삭제, 지역 제한 또는 원본을 가져올 수 없는 게시물은 저장하지 않고 다음 행동을 안내해요.

### 분석에서 제외하는 입력

- DM에 직접 첨부한 이미지
- DM에 직접 첨부한 동영상
- 장소 게시물 주소가 아닌 일반 글
- Instagram 프로필 주소
- Instagram 외부 주소
- 지원하지 않는 첨부파일

제외된 입력은 AI와 장소 검색에 전달하지 않으며 원문을 맛핀 DB에 저장하지 않습니다. 사용자가 올바른 공개 게시물을 보낼 수 있도록 유형별 사용 방법을 DM으로 답장해요.

## 5. 사용자 흐름

1. 사용자가 공개 장소 게시물의 공유 버튼에서 `matpin.kr`을 선택하거나 개별 게시물 링크를 보냅니다.
2. Webhook은 서명을 확인하고 지원 입력만 접수해요.
3. 맛핀은 접수 여부를 즉시 DM으로 알려줍니다.
4. 같은 미디어의 완료된 분석이 있으면 영구 캐시를 재사용합니다.
5. 처음 보는 미디어라면 캡션, 화면 정보, 음성 또는 확인 가능한 미디어에서 장소 단서를 추출해요.
6. 실제 지도 장소와 대조해 신뢰할 수 있는 후보를 최대 3곳까지 확정합니다.
7. 찾은 모든 장소를 사용자별 개인 보관함에 저장하고 가까운 역 기준으로 묶습니다.
8. 짧은 보관함 주소와 현재 저장 장소 수를 DM으로 보냅니다.

같은 사용자가 같은 게시물을 다시 보내도 AI 분석을 다시 실행하지 않습니다. 완료된 캐시는 만료일 없이 유지하며, 운영자가 실패 건을 명시적으로 재처리할 때만 해당 미디어 캐시를 무효화할 수 있어요.

## 6. 개인 보관함

- 사용자별 접근 토큰과 짧은 주소로 다른 사람의 보관함과 분리합니다.
- 저장한 장소를 가까운 역별로 묶고 최신 저장 순으로 보여줘요.
- 한 게시물에서 찾은 여러 장소를 모두 보존합니다.
- 장소 이름, 주소, 지도 주소, 원본 게시물 주소와 저장 시각을 제공합니다.
- 사용자는 저장 장소를 개별 삭제하거나 자신의 맛핀 데이터를 삭제할 수 있습니다.

## 7. Instagram 대화 경험

Instagram DM이 맛핀의 주 인터페이스입니다. 답장은 현재 상태와 다음 행동을 짧고 구체적으로 설명해야 해요.

- 접수: 릴스인지 게시물인지 구분하고 분석 시작을 알림
- 중복: 전에 보낸 게시물이며 기존 분석을 재사용한다고 안내
- 성공: 저장한 장소를 번호로 보여주고 짧은 보관함 주소 제공
- 장소 없음: 게시물은 확인했으나 장소를 찾지 못했다고 설명
- 지원 제외: 입력을 저장하지 않았다고 밝히고 올바른 공유 방법 안내
- 실패: 자동 처리할 수 없는 이유를 숨기지 않고 다른 공개 게시물 전송을 요청

## 8. 운영 CRM

관리자는 `/matpin/admin`에서 최근 Instagram 대화와 맛핀 처리 상태를 한 화면에서 확인합니다.

### 포함 범위

- 24시간, 7일, 30일, 전체 기간의 운영 지표
- 최근 대화 목록과 답장 필요, 처리 중, 저장 완료, 실패 필터
- Meta API에서 실시간으로 읽은 대화별 최근 메시지 최대 20건
- 사용자별 저장 장소와 최근 처리 이력
- 실패한 게시물 한 건 재처리
- 저장 장소가 있는 사용자에게 보관함 주소 재전송
- 최근 사용자 수신 후 24시간 미만인 대화에 비어 있지 않고 UTF-8 기준 1,000바이트 이하인 자유 문구 DM 발송
- 수신자와 최종 문구를 확인한 뒤 한 명씩 발송
- 관리자 행동의 성공 또는 실패 감사 기록

### 개인정보와 권한

- Supabase Google 로그인과 `MATPIN_ADMIN_EMAILS` 허용목록을 모두 통과해야 합니다.
- 허용목록이 비어 있으면 모든 관리자 접근을 거부해요.
- Instagram 이름, 사용자명, 프로필 이미지와 대화 원문은 Meta API에서 실시간으로만 읽습니다.
- 대화 원문, 임시 미디어 주소와 프로필 정보는 맛핀 DB에 영구 저장하지 않습니다.
- 감사 기록에는 관리자 ID, 발신자 해시, 행동 종류, 문구 길이와 SHA-256, Meta 메시지 ID, 성공 또는 실패만 남겨요.
- 서비스 역할 키, Instagram scoped ID와 access token은 브라우저 응답에 포함하지 않습니다.

## 9. 성공 지표

### 핵심 지표

- 지원 게시물 접수 대비 장소 저장 완료율
- 첫 게시물 공유부터 첫 장소 저장까지 걸린 시간
- 보관함 주소 재방문율
- 같은 게시물 분석의 캐시 적중률

### 운영 지표

- 처리 대기와 실패 건수
- 답장이 필요한 대화 수
- 저장 장소 수
- 분석 API 요청 수와 토큰 사용량
- 수동 복구 성공률

## 10. 범위에서 제외하는 기능

- DM으로 직접 보낸 글, 이미지, 동영상의 장소 분석
- 비공개 Instagram 게시물 분석
- 관리자 일괄 메시지, 첨부파일 발송, 예약 발송과 자동 캠페인
- 관리자 화면에서 사용자 삭제 또는 장소 수정
- 자동 메시지 요청 수락을 검증 없이 지원 완료로 간주하는 것

## 11. 출시 원칙

- 서비스는 지원 입력과 제외 입력을 명확하게 구분해야 합니다.
- 사용자의 직접 DM 원문을 저장하거나 AI에 보내지 않아요.
- 완료된 미디어 분석은 재사용해 중복 AI 비용을 만들지 않습니다.
- 공개 출시 전 Meta 권한과 역할이 없는 일반 계정의 실제 왕복 테스트를 다시 확인합니다.
- 운영 화면의 성공 표시는 실제 Meta 응답과 DB 상태가 확인된 경우에만 보여줍니다.
