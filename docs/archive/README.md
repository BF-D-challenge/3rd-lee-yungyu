# 문서 아카이브

이 영역은 맛핀의 현재 제품 판단에 사용하지 않는 과거 문서와 실험 자료를 보존하기 위한 안내입니다.

## 보존 방식

대규모 리서치 자료는 과거 스크립트와 테스트가 기존 경로를 직접 참조합니다. 경로를 한 번에 옮기면 재현 가능한 실험과 테스트가 깨지므로, 이번 정리에서는 원래 위치에 그대로 보존하고 논리적으로 아카이브했습니다.

경로 의존성이 없는 루트 문서는 `legacy-root/`로 실제 이동했고, 맛핀 이외의 과거 인수인계 문서는 `legacy-handoff/`에 보관합니다. 저장소 루트의 `TASK.md`는 맛핀 TASK로 연결하는 안내만 남겼어요.

이번 정리로 교체된 기존 README, PRD, TASK와 설계 계약의 원본은 정리 직전 Git 기준점 `b3d40b838a0b`에서 복구할 수 있습니다. 이 기준점은 역사 보존용이며 현재 제품 문서로 사용하지 않아요.

아래 경로는 모두 읽기 전용 역사 자료입니다.

- `docs/research/`
- `docs/dev/`
- `docs/design/`
- `docs/prd/`
- `docs/reports/`
- 맛핀 출시 기록을 제외한 `docs/handoff/`
- `legacy-root/docs/`의 광고, 전환 추적, 과거 UX와 배포 문서
- `legacy-root/repository/`의 과거 `TASK.md`와 `design-qa.md`
- `legacy-handoff/`의 과거 인수인계 문서

## 사용 규칙

1. 현재 맛핀 범위는 [맛핀 문서 허브](../matpin/README.md)에서만 판단합니다.
2. 아카이브 문서를 다시 활성화하려면 현재 코드와 운영 상태를 먼저 재검증해요.
3. 과거 수치와 출시 판정을 현재 사실처럼 인용하지 않습니다.
4. 파일 이동이 필요하면 참조하는 스크립트와 테스트를 같은 변경에서 함께 갱신합니다.

이 방식은 자료를 삭제하지 않으면서 활성 문서를 맛핀으로 한정합니다. 남은 대규모 자료의 물리 이동은 2,000개가 넘는 파일과 연결된 도구의 경로 마이그레이션이 필요하므로 별도 작업으로 다룹니다.
