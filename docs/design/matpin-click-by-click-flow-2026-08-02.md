- 대상: 모바일 Instagram + 모바일 웹
- 문서 목적: 사용자가 무엇을 누르고, 무엇을 보고, 다음에 어디로 가는지 한 장으로 이해한다.

## 0. 먼저 알아둘 표시

```text
[현재]   지금 코드에 있는 화면·동작
[새 기능] 앞으로 추가할 화면·동작
[조건부] 문제가 있을 때만 나타나는 화면
[Instagram] Instagram이 제공하는 버튼
[맛핀]   맛핀 웹과 서버가 제공하는 기능
```

맛핀은 별도 앱이 아니다. 사용자는 Instagram에서 릴스를 보내고, DM으로 받은 링크를 눌러 모바일 웹 지도를 연다.

## 1. 전체 그림 한 장

```text
┌──────────────────────────────────────────────────────────────────────────┐
│                          맛핀 전체 경험                                  │
└──────────────────────────────────────────────────────────────────────────┘

  [1. 맛집 릴스 발견]
           │
           │ [Instagram] 공유 버튼
           ▼
  [2. 받는 사람에서 matpin.kr 선택]
           │
           │ [Instagram] 보내기
           ▼
  [3. 맛핀이 장소 확인]
           │
           ├── 장소 1~3곳이 명확함 ───────┐
           │                              │
           ├── 지점이 애매함 ──> 확인 링크│
           │                              │
           └── 장소를 못 찾음 ─> 단어 요청│
                                          ▼
  [4. Instagram DM: “N곳을 모두 저장했어요” + 내 지도 링크]
           │
           │ [Instagram] 내 지도 보기 링크
           ▼
  [5. 내 비공개 지도]
           │
           ├── 핀 누르기 ─> 장소 상세 ─> 원본 릴스 / 길찾기
           │
           ├── 검색하기 ─> 장소 다시 찾기
           │
           └── [새 기능] 같이 갈 곳 보내기
                         │
                         │ 장소 1~5곳 선택 → 링크 만들기 → 공유
                         ▼
  [6. 친구가 공개 장소 묶음 링크를 받음]
           │
           │ 가입 없이 지도·장소·원본 릴스 확인
           ▼
  [7. 친구가 “내 지도에도 담기”]
           │
           │ 공유 링크를 Instagram의 matpin.kr DM으로 보냄
           ▼
  [8. 친구의 Instagram 아이디로 새 개인 지도 생성]
           │
           └──────── 친구도 장소 묶음을 다른 사람에게 공유 ───────┐
                                                                  │
                        <──────── 오가닉 바이럴 루프 ─────────────┘
```

### 가장 중요한 규칙

1. 사용자는 회원가입하지 않는다.
2. 지도는 릴스를 보낸 Instagram 아이디별로 나뉜다.
3. 한 릴스에 실제 장소가 여러 개면 확인된 장소를 전부 저장한다.
4. 친구에게 공유할 때는 전체 개인 지도가 아니라 사용자가 고른 1~5곳만 공개한다.
5. 친구는 결과를 먼저 보고, 마음에 들 때 자기 지도에 담는다.

## 2. JTBD — 사용자가 맛핀에게 맡기는 일

JTBD는 어려운 말 같지만 뜻은 간단하다. **사용자가 맛핀을 고용해 끝내고 싶은 일**이다.

### JTBD 1 — 나중에 갈 맛집 저장

> Instagram에서 나중에 가고 싶은 맛집 릴스를 봤을 때, 링크를 복사하거나 장소를 다시 검색하지 않고 한 번만 보내고 싶다. 그래야 나중에 실제 장소를 지도에서 바로 찾을 수 있다.

- 시작 상황: 릴스를 보고 있지만 지금 바로 방문하지는 않는다.
- 기존 불편: Instagram 저장함에 영상만 쌓여 장소를 다시 찾아야 한다.
- 원하는 결과: 실제 장소와 원본 릴스가 내 지도에 함께 남는다.
- 성공 행동: 릴스 전송 → 저장 완료 DM → 개인 지도 열기

### JTBD 2 — 약속할 장소 다시 찾기

> 친구와 어디 갈지 정할 때, 예전에 저장한 릴스를 끝없이 내리지 않고 지역이나 장소명으로 찾고 싶다. 그래야 원본 영상과 길찾기를 바로 열 수 있다.

- 시작 상황: 약속 장소를 정해야 한다.
- 원하는 결과: 검색 또는 지도 핀으로 후보를 찾는다.
- 성공 행동: 내 지도 열기 → 장소 선택 → 원본 릴스 또는 길찾기

### JTBD 3 — 같이 갈 곳 보내기

> 친구에게 맛집 후보를 보낼 때, 릴스 링크를 여러 개 따로 설명하지 않고 실제 장소 1~5곳을 한 번에 보내고 싶다. 그래야 친구가 쉽게 비교하고 답할 수 있다.

- 시작 상황: 친구·연인과 약속을 잡는다.
- 원하는 결과: 고른 장소와 원본 릴스가 한 링크에 들어간다.
- 성공 행동: 장소 선택 → 공개 링크 만들기 → 메시지 앱으로 공유

### JTBD 4 — 친구가 보낸 장소를 내 것으로 만들기

> 친구가 맛집 후보를 보냈을 때, 가입부터 하지 않고 장소를 먼저 보고 싶다. 마음에 들면 같은 장소를 내 지도에도 한 번에 담고 싶다.

- 시작 상황: 카카오톡이나 Instagram DM으로 장소 묶음 링크를 받았다.
- 원하는 결과: 가입 없이 내용을 보고, 내 Instagram 아이디 지도에 복사한다.
- 성공 행동: 링크 열기 → `내 지도에도 담기` → matpin.kr DM으로 링크 보내기

### JTBD 5 — 틀린 장소를 저장하지 않기

> 영상만으로 정확한 지점을 알 수 없을 때, 맛핀이 추측해서 틀린 곳을 저장하지 않았으면 한다. 필요한 경우 내가 한 번만 확인하고 싶다.

- 시작 상황: 같은 이름의 지점이 여러 개거나 장소 근거가 없다.
- 원하는 결과: 확인 가능한 곳만 저장하거나, 짧은 질문으로 복구한다.
- 성공 행동: 후보 확인 또는 가게명·지역 한 단어 답장

## 3. 사용자와 역할

```text
┌──────────────┐
│ 저장하는 사람 │  릴스를 matpin.kr에 보내 자기 지도를 만든다.
└──────────────┘
        │
        │ 고른 장소 링크 공유
        ▼
┌──────────────┐
│ 공유받은 친구 │  가입 없이 장소를 보고 자기 지도에 담을 수 있다.
└──────────────┘
        │
        │ 다시 장소 링크 공유
        ▼
┌──────────────┐
│ 다음 친구     │  같은 과정을 반복한다.
└──────────────┘

┌──────────────┐
│ matpin.kr     │  장소를 확인하고 Instagram 아이디별로 분리해 저장한다.
└──────────────┘
```

공유받은 친구도 자기 지도를 만들면 다음 저장자가 된다. 별도 추천인 가입은 없다.

## 4. 페이지 구조

주요 페이지는 세 개다. 나머지는 오류 복구와 개인정보 관리용이다.

```text
/matpin                         [현재] 사용 방법
   │
   ├── Instagram 열기 ───────> instagram.com/matpin.kr
   │
   └── 정책 보기 ────────────> /privacy /terms /data-deletion

/matpin/saved#token=...         [현재] 내 비공개 지도
   │
   ├── 장소 상세
   ├── 원본 릴스
   ├── 외부 지도
   ├── 장소 삭제
   └── 같이 갈 곳 보내기       [새 기능, 같은 화면의 바텀시트]

/s/{shareToken}                 [새 기능] 친구에게 공개한 장소 묶음
   │
   ├── 장소·지도·원본 릴스 보기
   └── 내 지도에도 담기

/matpin/confirm                 [조건부·현재] 지점 확인
/matpin/delete                  [현재] 전체 데이터 삭제
```

## 5. 시나리오 A — 처음 릴스 한 개 저장

### 상황

민지는 Instagram에서 가보고 싶은 성수동 식당 릴스를 본다. 맛핀을 처음 쓴다.

### 버튼 클릭 순서

```text
[Instagram 릴스]
   1. 민지: 종이비행기 모양 [공유] 버튼 누름
      ↓
[Instagram 공유 대상]
   2. 민지: 검색칸 누름
   3. 민지: “matpin.kr” 입력
   4. 민지: matpin.kr 계정 누름
   5. 민지: [보내기] 누름
      ↓
[맛핀 서버]
   6. 맛핀: 보낸 사람의 Instagram ID와 릴스 주소 확인
   7. 맛핀: 캡션 확인
   8. 맛핀: 작성자 댓글 확인
   9. 맛핀: 부족하면 영상 속 글자·말 확인
  10. 맛핀: Google Maps 근거가 있는 실제 장소 확인
  11. 맛핀: 민지의 개인 지도에 저장
      ↓
[Instagram DM]
  12. 민지: “성수다락을 내 지도에 저장했어요” 메시지 확인
  13. 민지: 메시지 안 [내 지도 보기] 링크 누름
      ↓
[/matpin/saved]
  14. 민지: 새로 저장된 핀 확인
  15. 민지: 핀 누름
  16. 민지: [원본 릴스] 또는 [지도에서 열기] 누름
```

### ASCII 화면 이동

```text
┌─────────────────┐     [공유]      ┌─────────────────┐
│ Instagram 릴스  │ ──────────────> │ 공유 대상 선택   │
└─────────────────┘                 └─────────────────┘
                                              │
                                    matpin.kr + [보내기]
                                              ▼
┌─────────────────┐   내 지도 링크   ┌─────────────────┐
│ 내 비공개 지도  │ <────────────── │ Instagram DM    │
└─────────────────┘                 └─────────────────┘
        │
        ├── [핀] ─> 장소 상세
        ├── [원본 릴스] ─> Instagram
        └── [지도에서 열기] ─> 외부 지도
```

### 끝난 상태

- 민지의 Instagram 아이디 전용 지도가 생긴다.
- 회원가입과 현재 위치 권한 요청은 없다.
- 첫 저장 완료가 가치 순간이다.

## 6. 시나리오 B — 한 릴스에 장소가 3곳

### 상황

민지가 `을지로 카페 3곳` 릴스를 matpin.kr에 보낸다.

### 버튼 클릭 순서

```text
1. 민지: 릴스 [공유]
2. 민지: matpin.kr 선택
3. 민지: [보내기]
4. 맛핀: 서로 다른 실제 장소 3곳을 확인
5. 맛핀: 민지에게 하나만 고르라고 묻지 않음
6. 맛핀: 3곳 모두 저장
7. 민지: DM의 “찾은 장소 3곳을 모두 저장했어요” 확인
8. 민지: [내 지도 보기]
9. 민지: 새 핀 3개 확인
10. 민지: 각 핀을 눌러 장소별 상세 확인
```

### 상태 흐름

```text
릴스 1개
   │
   ├── 장소 A: 카페 오브젝트 ─┐
   ├── 장소 B: 커피 한약방   ├──> [모두 저장]
   └── 장소 C: 챔프커피       ┘
                                  │
                                  ▼
                         같은 개인 지도에 핀 3개
```

### 참조 화면

- Canopi의 [결과 목록](https://mobbin.com/screens/d88f4063-64d0-4234-9afc-433ca89af1be)처럼 릴스 한 개 아래 장소 미리보기 3개를 작게 보여준다.
- Canopi의 [겹친 상세 카드](https://mobbin.com/screens/246066eb-4a3b-4076-94ee-540ae6789009)처럼 서로 다른 장소가 같은 릴스에서 왔다는 관계를 보인다.

## 7. 시나리오 C — 두 번째 릴스를 반복 저장

### 상황

민지는 며칠 뒤 또 다른 맛집 릴스를 발견한다. matpin.kr가 최근 DM 대상에 보인다.

```text
1. 민지: 새 릴스 [공유]
2. 민지: 최근 대화에서 matpin.kr 바로 누름
3. 민지: [보내기]
4. 맛핀: 민지의 기존 Instagram-scoped ID 확인
5. 맛핀: 새 장소만 기존 지도에 추가
6. 민지: DM의 같은 개인 지도 링크 누름
7. 지도: 이번에 추가된 핀을 먼저 강조
```

```text
첫 릴스 ──────┐
              ├── 같은 Instagram ID ──> 개인 지도 하나
두 번째 릴스 ─┘                            │
                                           ├── 기존 장소
                                           └── 새 장소
```

새 지도나 새 계정을 만들지 않는다. 반복 저장이 쉬워지는 것이 핵심이다.

## 8. 시나리오 D — 저장 장소 다시 찾기

### 상황

민지가 친구와 성수에서 만난다. 예전에 저장한 식당을 찾고 싶다.

### 버튼 클릭 순서

```text
1. 민지: Instagram의 matpin.kr DM 열기
2. 민지: 가장 최근 [내 지도 보기] 링크 누름
3. 지도: 저장 장소 핀과 하단 목록 표시
4-A. 민지: 지도 핀 누름
   또는
4-B. 민지: [장소, 지역, 주소 검색] 입력칸 누름
5. 민지: “성수” 입력
6. 민지: 검색 결과의 장소 행 누름
7. 지도: 장소 상세 시트 열림
8-A. 민지: [원본 릴스] 누름 → Instagram에서 영상 확인
8-B. 민지: [지도에서 열기] 누름 → 외부 지도에서 길찾기
```

### 지도 버튼 지도

```text
┌──────────────────────────────────┐
│ [<]  내 위치를 사용하지 않아요  [IG]│
│                                  │
│       [핀1]       [핀2]          │
│             SEOUL                │
│    [핀3]                         │
│                                  │
├──────────────────────────────────┤
│ ─────  [저장한 장소 12곳] [∨]    │
│ [검색: 장소, 지역, 주소]    [X]   │
│                                  │
│ 1  성수다락 · 성수 · 이탈리안    │ ← 누르면 상세
│ 2  난포 · 성수 · 한식             │
│                                  │
└──────────────────────────────────┘
```

### 상세 상태

```text
┌──────────────────────────────────┐
│ 성수다락                         │
│ 성수 · 이탈리안                  │
│ 서울 성동구 ...                  │
│                                  │
│ [원본 릴스] [지도에서 열기]       │
│ [같이 갈 곳 보내기]              │  ← 새 기능
│                                  │

```

## 9. 시나리오 E — 같이 갈 곳을 친구에게 보내기

### 상황

민지가 친구 준호에게 성수 맛집 후보 3곳을 보내고 싶다.

### 버튼 클릭 순서

```text
1. 민지: 내 지도에서 첫 장소 핀 누름
2. 민지: [같이 갈 곳 보내기] 누름
3. 맛핀: 화면 아래에서 장소 선택 시트 열기
4. 맛핀: 지금 본 장소 1곳을 기본 선택
5. 민지: [장소 더 고르기] 누름
6. 민지: 두 번째 장소 체크
7. 민지: 세 번째 장소 체크
8. 맛핀: 하단 버튼을 [3곳 링크 만들기]로 갱신
9. 민지: [3곳 링크 만들기] 누름
10. 맛핀: 선택한 장소만 들어간 공개 링크 생성
11. 맛핀: 상단에 “공유 링크를 만들었어요” 표시
12. 민지: [공유하기] 누름
13. 휴대폰: OS 공유 시트 열기
14. 민지: 카카오톡 또는 Instagram 선택
15. 민지: 준호 선택
16. 민지: [보내기] 누름
```

### 선택 시트

```text
┌──────────────────────────────────┐
│ 내 비공개 지도                   │
│    [핀] [핀] [핀]                │
│                                  │
├──────────────────────────────────┤
│ ─────                            │
│ 같이 갈 곳을 골라주세요          │
│ 친구에게는 고른 장소만 보여요.   │
│                                  │
│ [✓] 성수다락                     │
│ [ ] 난포                         │
│ [ ] 대림창고                     │
│ [ ] 센터커피                     │
│                                  │
│ [취소]        [1곳 링크 만들기]  │
└──────────────────────────────────┘
```

### 선택 규칙

- 최소 1곳, 최대 5곳이다.
- 기본값은 지금 보고 있던 장소 1곳이다.
- 5곳을 고르면 다른 체크박스는 비활성화하고 `최대 5곳까지 보낼 수 있어요`라고 설명한다.
- `취소`를 누르면 아무 링크도 만들지 않고 원래 장소 상세로 돌아간다.
- 뒤로 갔다 다시 열어도 아직 링크를 만들지 않았다면 선택값은 유지한다.

### 화면 4 — `/s/{shareToken}` 공개 장소 묶음

| 표시 이름 | 누르면 | 성공 | 실패·취소 |
| --- | --- | --- | --- |
| 장소 카드 | 상세 펼치기 | 주소·원본·지도 행동 표시 | 다시 누르면 접기 |
| 지도 핀 | 해당 장소 카드로 이동 | 선택 강조 | 없음 |
| 원본 릴스 | Instagram 릴스 | 영상 확인 | 원본이 없으면 버튼 숨김 |
| 지도에서 열기 | 외부 지도 | 장소 확인·길찾기 | 새 탭 닫기 |
| 내 지도에도 N곳 담기 | 가져오기 안내 시트 | Instagram 전송 방법 표시 | `취소`로 원래 화면 |
| 맛핀은 어떻게 쓰나요? | `/matpin` | 사용 안내 | 브라우저 뒤로 복귀 |

### 화면 5 — 가져오기 안내 시트

| 표시 이름 | 누르면 | 성공 | 실패·취소 |
| --- | --- | --- | --- |
| Instagram으로 보내기 | Web Share API | 공유 시트에 현재 링크 전달 | 지원하지 않으면 대체 버튼 강조 |
| 링크 복사하고 matpin.kr 열기 | 복사 후 프로필 열기 | 사용자가 DM에 붙여넣을 수 있음 | 복사 실패면 링크 선택 가능하게 표시 |
| 취소 | 시트 닫기 | 공개 장소 묶음 복귀 | 데이터 변화 없음 |

## 19. 데이터가 누구 것인지

```text
Instagram ID: 민지
   └── 민지의 개인 지도
       ├── 저장 장소 A
       ├── 저장 장소 B
       ├── 저장 장소 C
       └── 공개 링크 1 ──> A, C만 포함

Instagram ID: 준호
   └── 준호의 개인 지도
       └── 공개 링크 1을 DM으로 보낸 뒤 A, C 복사

민지의 비밀 지도 링크 ≠ 준호의 비밀 지도 링크
공개 링크에는 민지가 선택한 A, C만 보임
```

- 공개 링크에 개인 지도 비밀 토큰을 넣지 않는다.
- 공유자의 Instagram 아이디를 공개하지 않는다.
- 공유받은 친구가 가져와도 서로의 지도는 연결되지 않는다.
- 같은 장소를 가져오더라도 각자의 삭제·검색·재사용은 독립적이다.

## 20. 오가닉 바이럴 K가 생기는 지점

```text
민지의 첫 가치
   “장소가 내 지도에 저장됐다”
              │
              ▼
민지의 자연스러운 행동
   “준호야, 우리 여기 어때?”
              │
              ▼
준호의 첫 가치
   “가입 없이 장소 3곳을 봤다”
              │
              ▼
준호의 전환
   “이 장소들을 내 지도에도 담았다”
              │
              ▼
준호의 다음 공유
   “다른 친구에게 자기 장소 묶음을 보냈다”
```

서비스를 추천하라고 요구하지 않는다. 약속 장소를 고르는 실제 행동이 자연스럽게 다음 사용자를 만든다.

## 24. 완료 조건

### 저장 과업

- 사용자가 Instagram에서 matpin.kr로 릴스를 보낼 수 있다.
- 장소 1~3곳이 모두 같은 Instagram 아이디 지도에 저장된다.
- 결과 DM의 링크가 오류 없이 열린다.

### 재사용 과업

- 지도 핀과 검색 모두 장소 상세로 이어진다.
- 원본 릴스와 외부 지도 버튼이 실제 URL을 연다.
- 삭제 실패 시 장소가 화면에서 먼저 사라지지 않는다.

### 공유 과업

- 사용자가 1~5곳만 골라 공개 링크를 만든다.
- 친구가 가입 없이 선택 장소만 본다.
- 전체 개인 지도와 공유자 Instagram 아이디는 노출되지 않는다.
- 친구가 공유 링크를 matpin.kr DM으로 보내 자기 지도에 담는다.
- 같은 공유 링크를 다시 보내도 장소가 중복되지 않는다.
- 보낸 사람이 공개 링크를 철회할 수 있다.

### 이해 과업

중학생에게 다음 질문을 했을 때 한 문장으로 답할 수 있어야 한다.

1. 맛핀에 장소를 어떻게 저장하나요?
   - `Instagram 릴스를 matpin.kr 계정으로 보내요.`
2. 지도는 누구 기준인가요?
   - `릴스를 보낸 Instagram 아이디 기준이에요.`
3. 한 릴스에 장소가 여러 개면요?
   - `확인된 장소는 모두 저장해요.`
4. 친구에게 무엇이 보이나요?
   - `내가 고른 장소만 보여요.`
5. 친구는 어떻게 자기 지도에 담나요?
   - `받은 링크를 Instagram에서 matpin.kr에 보내요.`
