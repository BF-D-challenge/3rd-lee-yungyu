# 한입코치 팩폭·복귀 루프 계약

## Product Truth

- 사용자: 체지방을 줄이고 싶지만 식단 기록을 며칠 만에 포기하는 20~30대 직장인
- 문제: 흔들린 한 끼를 망한 하루로 키우고 다음 끼니까지 놓친다.
- 입력: 사용자가 직접 고른 음식 사진 한 장과, 재방문 시 지난 행동의 실행 여부
- 결과: 사진에서 확인한 음식 이름·그룹에 맞춰 Gemini가 자유 생성한 황당하게 웃긴 팩폭 한 문장과 다음 끼니 행동 하나
- 가치 순간: 몸이나 인격을 공격하지 않는 코미디 팩폭에 웃고, 다음 행동을 약속하는 순간
- 주 행동: `이 행동으로 약속하기`
- primary metric: 사진 분석 성공 뒤 다음 끼니 행동 저장률
- guardrail: 의료·섭식 위험 결과 차단, 사진 저장 0건, 모욕·외모·체중 평가 0건
- 범위 밖: 칼로리·중량·질환 판단, 식단 치료, 실제 결제와 자동 갱신

## Journey

`사진 제출 → 음식 이름·그룹 확인 → 팩폭 → 다음 끼니 행동 약속 → 다음 사진과 실행 여부 확인 → 새 팩폭`

- 첫 코칭은 로그인이나 결제 전에 무료로 제공한다.
- 팩폭은 Gemini가 사진마다 자유 생성한다. 음식 의인화·과장된 사건·속보체·엉뚱한 비유·반전 중 한 장치를 골라, 보이는 음식 이름을 넣은 한 문장으로 만든다. 점잖은 영양 상담 문구는 실패로 본다.
- 몸·체중·외모·인격·질환 공격과 굶기·보상 운동 표현은 서버가 차단하고, 같은 코미디 톤의 안전 문장으로 교체한다.
- 다음 사진에서 사진 파일 자체로 실행 여부를 단정하지 않는다. 사용자가 `해봤어요 / 아직 못 했어요`로 직접 기록한다.
- 공유에는 음식 사진이나 개인 정보를 넣지 않고 팩폭과 다음 행동, 공개 진입 주소만 사용한다.
- 7일 패스는 준비 중이다. `4,900원 · 자동 갱신 없음`을 알리되 실제 결제처럼 보이지 않게 출시 알림으로 연결한다.

## Interaction Contract

| 표시 이름 | 실제 행동 | 성공 | 실패·취소 |
|---|---|---|---|
| 음식 사진 한 장 고르기 | 로컬 파일 선택 | 미리보기 표시 | 형식·크기 오류 안내 |
| 사진 속 음식 확인하기 | `/api/onebite/analyze` POST | 음식 이름·그룹과 동적 팩폭 준비 | 재촬영·안전 경계·재시도 안내 |
| 맞아요, 팩폭 들을게요 | 화면 상태 전환 | 전체 화면 팩폭 표시 | 음식 확인으로 되돌아가기 |
| 다음 한입 약속 보기 | 화면 상태 전환 | 행동 하나만 표시 | 팩폭으로 되돌아가기 |
| 이 행동으로 약속하기 | localStorage에 행동 저장 | 다음 방문에 복원 | 저장 공간 오류 안내 |
| 오늘의 팩폭 공유하기 | Web Share, 미지원 시 clipboard | 공유·복사 완료 안내 | 취소는 조용히 종료, 오류는 재시도 안내 |
| 해봤어요 / 아직 못 했어요 | 사용자가 실행 여부 선택 | 다음 분석과 함께 기록 | 미선택 시 제출 비활성 이유 표시 |
| 7일 패스 알림 받기 | `/reserve/onebite` 이동 | 출시 알림 신청 화면 | 결제·자동 갱신이 아님을 반복 안내 |

## Design Read

- 목적: 팩폭을 읽고 다음 끼니 행동 하나를 약속한다.
- 인지 순서: 1) 오늘의 팩폭 2) 복귀 행동 3) 확인 근거 4) 약속 5) 공유·다음 사진
- 기억 단서: 코랄 팩폭 카드와 초록 복귀 행동 카드의 대비
- DESIGN_VARIANCE: 6/10 — 익숙한 단일 열 안에 팩폭 단계만 포스터처럼 크게 전환
- MOTION_INTENSITY: 1/10 — 버튼 press와 로딩 상태만 사용, 결과 연출 지연 없음
- VISUAL_DENSITY: 5/10 — 결과·근거·행동·후속 CTA를 한 화면 흐름으로 유지

## Voice Boundary

- 공격 가능: 확인된 선택, 반복 패턴, 지금 만들 핑계
- 공격 금지: 몸, 체중, 외모, 인격, 의지, 직업, 질환, 섭식 상태
- 웃음 장치: 음식 의인화, 황당한 사건, 진지한 속보, 엉뚱한 비유, 반전
- 실패 문구: 무난한 영양 상담, 흔한 결석·투명인간 비유, 교훈부터 말하는 잔소리
- 모든 팩폭은 굶기·보상 운동이 아니라 다음 끼니의 작은 일반 행동으로 끝낸다.
