# Idea Lab 익명 가치 우선 여정 7일 검증 계획

## 검증할 결정

로그인과 공유를 요구하지 않아도 사용자가 네 장의 의미를 따라가며 결과를 이해하고, 결과를 실제 다음 행동에 쓰는지 확인한다. 이번 검증에서는 기능 A/B 테스트를 하지 않는다. 예시 온보딩, 타로 연출, 공유 루프 확장은 결과를 본 뒤에만 판단한다.

## 대상 12명

- 아이디어가 없는 사람 6명
- 아이디어는 있지만 범위를 줄이지 못하는 사람 6명

두 집단 모두 같은 빌드와 같은 안내를 사용한다. 사전에 Idea Lab의 카드 의미나 결과 구조를 설명하지 않는다.

## 진행

1. 새 브라우저 상태에서 홈을 연다.
2. 진행자가 말하는 첫 과업은 `오늘 만들 만한 아이디어 하나를 완성해 주세요.` 하나뿐이다.
3. 결과에 도달하면 `이 아이디어가 누구의 어떤 문제를 어떻게 바꾸는지 본인 말로 설명해 주세요.`라고 묻는다.
4. 저장, 복사, 공유, 제작 중 무엇을 할지는 지시하지 않고 관찰한다.
5. 24시간 뒤 실제로 복사, 저장, 또는 제작을 시작했는지 확인한다.

## 기록

- 결과 도달 여부와 도달 시간
- 네 카드에서 다음 버튼을 누르기 전 체류 시간
- 결과 설명의 대상, 순간, 한 끗 변화 포함 여부
- 프롬프트 복사, 이 기기 저장, 자발적 공유, 결과 뒤 로그인 여부
- 24시간 안에 복사한 내용을 다시 사용했거나 제작을 시작한 증거
- 중단 지점과 참가자의 말은 분석 이벤트가 아니라 인터뷰 기록에만 남긴다.

이벤트로 이해도를 단정하지 않는다. `result_ready`와 `result_viewed`의 차이는 여정 이탈만 보여주며, 이해 여부는 참가자의 자기 설명으로 판정한다.

## 성공 기준

- 12명 중 10명 이상 결과 도달
- 12명 중 8명 이상 결과를 자기 말로 설명
- 12명 중 5명 이상 24시간 안에 복사, 저장, 제작 중 하나 실행

## 집단별 해석

- 이해도가 낮으면 카드별 의미와 결과 설명을 먼저 개선한다.
- 이해하지만 행동하지 않으면 타깃 적합성과 결과의 실용성을 재검토한다.
- 아이디어 보유 집단이 더 좋으면 제품 포지션을 `아이디어 생성`보다 `아이디어 구체화`로 이동한다.
- 두 집단 모두 약하면 해결하려는 핵심 문제를 다시 정의한다.
- 두 집단 모두 좋으면 그다음 실험에서만 예시 온보딩, 타로 연출, 자연 공유 루프를 검토한다.

## 7일 운영

- 1일차: 두 집단 각 1명으로 진행 문구와 기록표 점검
- 2~5일차: 하루 2~3명씩 본 세션 진행
- 6일차: 24시간 후 행동 확인과 집단별 결과 집계
- 7일차: 성공 기준 판정, 다음 한 가지 제품 결정 기록

이번 실험의 결론은 전체 평균과 두 집단의 결과를 함께 본다. 표본 12명의 비율을 시장 전체 전환율로 일반화하지 않는다.
