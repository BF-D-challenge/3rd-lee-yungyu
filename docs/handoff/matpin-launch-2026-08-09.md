# 맛핀 2026-08-09 출시 체크포인트

이 파일은 2026-08-09 당시의 출시 판단을 남기는 역사적 체크포인트입니다. 현재 운영 절차와 상태는 [맛핀 운영 문서](../matpin/OPERATIONS.md), 데이터 흐름과 보안 계약은 [맛핀 아키텍처](../matpin/ARCHITECTURE.md)를 기준으로 확인해요.

## 당시 판단

- 앱 역할과 승인된 테스트 계정 대상 비공개 베타는 진행 가능한 상태로 판단했습니다.
- 일반 공개는 Meta 메시지 권한의 고급 액세스와 앱 역할이 없는 계정의 실제 왕복 확인 전까지 보류했어요.
- 운영 Webhook, 법적 고지, 개인 보관함과 데이터 삭제 진입점을 출시 필수 범위로 두었습니다.

이 판단은 현재 권한이나 배포 상태를 증명하지 않습니다. 공개 범위를 바꾸기 전에 Meta 앱 상태와 최신 운영 배포를 다시 확인해야 해요.

## 검수 시나리오

1. Instagram에서 공개 음식점 게시물을 엽니다.
2. 공유 버튼으로 `matpin.kr`에 게시물을 보내요.
3. 같은 대화에서 접수 답장과 저장 완료 답장을 확인합니다.
4. 짧은 개인 보관함 링크를 열고 장소가 저장됐는지 봐요.
5. `/matpin/delete`에서 장소 삭제와 전체 데이터 삭제 진입점을 확인합니다.
6. 개인정보처리방침, 이용약관과 데이터 삭제 안내를 확인해요.

릴스뿐 아니라 공개 피드 게시물과 캐러셀도 같은 흐름으로 검증합니다. DM에 직접 보낸 글, 이미지와 동영상은 분석하지 않고 사용 방법 안내만 보내야 해요.

## 남겨야 할 증거

- 사용자가 게시물을 공유하고 보관함을 여는 실제 왕복 화면
- 의도한 Git SHA와 같은 Vercel Ready 배포
- 운영 별칭과 실제 렌더링 화면의 일치
- Webhook 서명 검증과 잘못된 서명 거절
- 개인 보관함과 데이터 삭제 동작

최신 점검 명령과 관리자 CRM 검증 절차는 [맛핀 운영 문서](../matpin/OPERATIONS.md#배포-전-검증)를 사용합니다.
