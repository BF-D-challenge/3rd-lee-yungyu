# 맛핀 문서 허브

맛핀의 제품, 기술, 운영과 화면 설계 정본을 한곳에서 찾는 시작 문서입니다.

## 먼저 읽을 문서

1. [제품 요구사항](../PRD.md)에서 누구의 어떤 문제를 풀고 어디까지 지원하는지 확인합니다.
2. [현재 TASK](../TASK.md)에서 구현 상태와 출시 전 남은 일을 확인해요.
3. [기술 구조](ARCHITECTURE.md)에서 Instagram 수신부터 개인 보관함까지의 데이터 경계를 봅니다.
4. [운영 가이드](OPERATIONS.md)에서 환경 변수, 배포, 실사용 검증과 장애 대응을 확인해요.

날짜가 붙은 자료는 당시 확인한 근거입니다. 구현과 운영의 현재 정본은 날짜가 없는 활성 문서에서 관리합니다.

## 문서 경계

- 활성 문서는 맛핀만 설명합니다.
- DM으로 직접 보낸 글, 사진과 동영상 원문은 제품 데이터나 리서치 자료로 저장하지 않습니다.
- 비밀값, 개인 보관함 토큰, Instagram scoped ID와 임시 미디어 URL을 문서에 넣지 않아요.
- 과거 리서치와 실험 파일은 추적성을 위해 보존하지만 현재 범위의 근거로 자동 승격하지 않습니다.
- 비맛핀 자료와 과거 실험은 [문서 아카이브](../archive/README.md)에서 관리해요.
