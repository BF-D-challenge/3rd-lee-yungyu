# 맛핀 관리자 CRM 레퍼런스 결정 기록

작성일: 2026-08-09

문서 상태: 맛핀 관리자 CRM의 화면 구조와 구현 경계를 정한 근거 문서입니다.

## 목표

운영자가 답장 필요와 처리 실패를 빠르게 발견하고, 다른 화면으로 이동하지 않은 채 최근 대화와 사용자 저장 맥락을 확인한 뒤 한 건씩 복구할 수 있는 데스크톱 우선 CRM을 설계했습니다.

## 검증한 화면

### 1. Intercom, Inbox 대화 구조

- 원본: [Mobbin 화면](https://mobbin.com/screens/80784ca7-28c5-4282-80cf-26ac4909431a)
- OCR 확인: inbox 필터, 열린 대화 목록, 선택 대화, 우측 고객과 대화 출처 맥락이 한 화면에 함께 존재했습니다.
- 가져온 원리: 목록, 대화, 고객 맥락의 3단 배치와 선택 상태 유지
- 버린 원리: 팀 배정, SLA, 상담원 협업 메뉴는 1인 운영 v1에 필요하지 않아 제외했습니다.

### 2. HubSpot, 상태 필터와 고객 상세

- 원본: [Mobbin 화면](https://mobbin.com/screens/f486dfbd-2f24-4bde-9a45-68ab53b8eca5)
- OCR 확인: 대화 필터, 대화 본문, 연락처 프로필과 행동이 병렬로 배치되어 있었습니다.
- 가져온 원리: 전체, 답장 필요, 처리 중, 저장 완료, 실패 필터와 사용자별 상세 맥락
- 버린 원리: CRM 속성 편집과 거래 파이프라인은 맛핀 데이터 수정 범위에 포함하지 않았습니다.

### 3. Sentry, 실패 원인과 복구 행동

- 원본: [Mobbin 화면](https://mobbin.com/screens/e540ee91-daff-4293-8983-1c95880f5009)
- OCR 확인: 이슈 상태, 원인, 해결 정보, 활동 이력이 같은 상세 문맥 안에 배치되어 있었습니다.
- 가져온 원리: 실패 상태 가까이에 마지막 오류, 시도 횟수, 다시 처리 행동을 함께 표시
- 버린 원리: 스택 추적과 코드 소유자 정보는 운영 담당자에게 불필요해 제외했습니다.

### 4. Stripe, 기간별 상단 요약

- 원본: [Mobbin 화면](https://mobbin.com/screens/02176a39-e453-4570-af73-6af00fbe681b)
- OCR 확인: 기간 선택, 결제 상태와 실패 지표, 고객 지표가 상단 요약에 모여 있었습니다.
- 가져온 원리: 24시간, 7일, 30일, 전체 기간 전환과 한 줄 운영 지표
- 버린 원리: 큰 추이 차트는 대화를 가리고 현재 데이터 규모에서 판단 가치를 만들지 못해 제외했습니다.

## 최종 전이 결정

| 영역 | 구현 결정 | 근거 |
|---|---|---|
| 상단 | 지표 8개와 기간 선택 | Stripe의 기간별 요약을 대화를 가리지 않는 높이로 축소 |
| 왼쪽 | 상태 필터와 최근 대화 | Intercom과 HubSpot의 스캔 가능한 목록 구조 |
| 가운데 | Meta 최근 메시지 20건과 답장 | Intercom의 대화 집중 구조, Meta API 제한과 일치 |
| 오른쪽 | 프로필, 처리 상태, 실패 원인, 저장 장소 | HubSpot 고객 맥락과 Sentry 복구 행동 결합 |
| 모바일 | 목록과 대화 전환, 맥락 시트 | 3단 정보를 축소하지 않고 과업 단위로 분리 |

## Design Read

- Design Read: 문제 발견과 복구를 한 화면에서 끝내는 고밀도 운영 도구입니다.
- `DESIGN_VARIANCE 3`
- `MOTION_INTENSITY 1`
- `VISUAL_DENSITY 8`
- 어두운 불투명 표면과 한글 시스템 폰트를 사용합니다. 글래스, 장식용 그라데이션, 큰 차트는 쓰지 않아요.

## 구현 경계

- 최근 대화와 프로필 및 메시지 원문은 Meta API에서 실시간 조회합니다.
- 사용자가 직접 보낸 글, 이미지, 동영상 원문은 DB와 AI 분석 입력에 저장하지 않습니다.
- 수동 DM은 수신자와 최근 메시지 및 최종 문구를 확인하고 한 명씩만 발송합니다.
- 사용자 삭제, 장소 수정, 일괄 메시지, 첨부파일 발송, 예약 발송과 자동 캠페인은 v1에서 제외했습니다.
