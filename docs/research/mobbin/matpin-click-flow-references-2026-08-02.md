# 맛핀 클릭 플로우용 Crème·Canopi 화면 선택

결론: Crème에서는 `상세 행동·저장 피드백·저장 목록·공유 행동`, Canopi에서는 `빈 상태·선택 시트·결과 요약·묶음 상세`를 가져온다. 친구·팔로우·수동 컬렉션 기능은 가져오지 않는다.

## 조사 브리프

- 사용자 과업: Instagram 릴스를 보내 장소를 저장하고, 다시 찾고, 친구에게 고른 장소만 보낸다.
- 진입 트리거: 맛집 릴스 발견 또는 친구가 보낸 장소 묶음 링크
- 현재 기준선: DM 자동 저장과 비공개 개인 지도는 있으나 장소 묶음 공유는 아직 없다.
- 가치 순간: 장소가 내 지도에 저장되거나, 친구가 보낸 장소를 가입 없이 바로 확인한 순간
- 검토할 요청: 가입·위치 권한·결제 없음
- 결정: 버튼 클릭 단위 플로우에 붙일 실제 모바일 화면 선택
- 목표 지표: 첫 저장 완료, 지도 재방문, 공유 수신자의 첫 저장
- guardrail: 사용자 간 데이터 혼합 0건, 전체 개인 지도 실수 공개 0건
- 가정: 장소 추천을 주고받는 순간이 맛핀의 자연스러운 오가닉 공유 순간이다.

## Crème

![Crème에서 고른 네 화면](assets/matpin-click-flow-references-2026-08-02/creme-reference-board.jpg)

1. [상세 화면](https://mobbin.com/screens/1fd7eb47-6704-44e8-bc3a-45a91b22627a): 큰 콘텐츠 아래에 `Cook · Plan · Remix · Ask`를 한 줄로 둔다. 맛핀 장소 상세의 `원본 릴스 · 길찾기 · 같이 갈 곳 보내기`에 맞춘다.
2. [저장 완료 피드백](https://mobbin.com/screens/9cce0c35-df8e-4798-a6e3-a1c894bc71a3): 화면을 바꾸지 않고 상단에 `Added to your plans`를 보여준다. 맛핀의 저장 완료와 링크 복사 완료 피드백에 맞춘다.
3. [저장 목록](https://mobbin.com/screens/830af067-a5dc-4dfb-b808-50f5ec41cb9b): 큰 사진 카드 네 개로 저장 결과를 바로 알아보게 한다. 맛핀 공개 장소 묶음과 지도 하단 목록에 맞춘다.
4. [공유 행동](https://mobbin.com/screens/df1c1596-913b-4fb1-93f5-1ae7f0d81985): 화면 아래에 `Message · Copy link · Share`를 고정한다. 맛핀 공유 시트의 `Instagram으로 보내기 · 링크 복사`에 맞춘다.

- 관찰 E0: 상세·저장·재방문·공유 상태마다 행동이 화면 아래 또는 콘텐츠 바로 아래에 붙어 있다.
- 전이 판단: adapt — 행동 위치와 즉시 피드백을 쓰되, 친구 검색·팔로우·초대 목록은 맛핀에 넣지 않는다.
- 위험·한계: Crème은 레시피 앱이며 지도·Instagram DM 제품이 아니다.
- 출처: [Crème 앱](https://mobbin.com/apps/creme-ios-2437b570-6f06-4b2a-a683-834d6a6ee2de)

## Canopi

![Canopi에서 고른 네 화면](assets/matpin-click-flow-references-2026-08-02/canopi-reference-flow.jpg)

1. [빈 상태](https://mobbin.com/screens/b19a1cc5-4dae-4c99-8855-1ee3f0e7e8ad): 제품 설명과 첫 행동 한 개만 가운데 둔다. 맛핀의 저장 장소 0곳 상태에 맞춘다.
2. [선택 시트](https://mobbin.com/screens/4dec5284-1d51-46c5-a516-2d3ba2054aa8): 아래에서 열린 시트 안에서 한 가지 결정을 끝낸다. 맛핀의 `같이 갈 곳 1~5곳 선택`에 맞춘다.
3. [결과 목록](https://mobbin.com/screens/d88f4063-64d0-4234-9afc-433ca89af1be): 하나의 묶음에 들어 있는 날짜·지도·할 일을 작은 미리보기로 보여준다. 맛핀의 릴스별 장소 미리보기와 공유 전 요약에 맞춘다.
4. [겹친 상세 카드](https://mobbin.com/screens/246066eb-4a3b-4076-94ee-540ae6789009): 서로 다른 정보 카드가 같은 사건 아래 묶여 있다. 맛핀에서 한 릴스의 여러 장소나 친구가 고른 여러 장소를 한 묶음으로 보여주는 데 맞춘다.

- 흐름: EMPTY → CHOOSE → RESULT → DETAIL; 가입·권한·결제 요청 없음
- 관찰 E0: 빈 상태에서 바로 만들기를 시작하고, 완성 뒤에는 여러 종류의 정보를 작은 카드 묶음으로 요약한다.
- 전이 판단: adapt — 빈 상태와 묶음 구조를 쓰되, 여행·기념일 템플릿을 고르게 하지는 않는다.
- 위험·한계: Canopi의 수동 컬렉션 제작은 자동 저장이 핵심인 맛핀에 그대로 맞지 않는다.
- 출처: [Creating a collection](https://mobbin.com/flows/ebcaea14-7195-48d5-9a03-f3387e6ca479)

## 반복 패턴과 예외

- 반복 E1: 두 앱 모두 `큰 결과 → 가까운 행동 → 즉시 상태 변화` 순서를 사용한다.
- counterexample: Crème의 친구 검색·초대와 Canopi의 템플릿 선택은 기능을 늘린다. 맛핀은 Instagram의 기존 공유 행동을 사용하므로 제외한다.

## 맛핀에 적용

1. 개인 지도 상세 행동은 Crème처럼 선택한 장소 바로 아래에 둔다.
2. 공유 장소 선택은 Canopi처럼 같은 화면의 바텀시트에서 끝낸다.
3. 저장·링크 복사 성공은 화면 이동 대신 짧은 상태 문구로 알린다.
4. 공개 장소 묶음은 사진 카드와 작은 지도만 먼저 보여주고 가입을 요구하지 않는다.

> Mobbin 화면은 출시된 구조의 근거이며 성과·규정 준수의 증거가 아니다.
