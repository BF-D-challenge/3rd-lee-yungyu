# 맛핀 수정 첫 화면 3안

Poly 실제 첫 화면과 첫 스크롤 전환을 다시 캡처한 뒤 제작했다. 세 안 모두 흩어진 릴스가 아니라 `제품 약속 + 하나의 안정된 제품 화면`으로 시작한다.

공통 조건:

- 모바일 390 × 844
- 다크 디지털 무대
- 책상, 방, 노트북, 종이 사용 안 함
- 제품 화면 하나만 배치
- 다음 스크롤에서 제품 화면이 기울고 릴스를 방출할 수 있는 구조
- Built-in ImageGen 사용

선택 후에는 선택한 제품 화면을 기준으로 `고정 → 기울기 → 릴스 방출 → 흩어진 릴스` 전환 프레임을 제작한다.
