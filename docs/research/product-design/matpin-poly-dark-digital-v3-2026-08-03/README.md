# 맛핀 다크 디지털 월드 스토리보드 v3

생성일: 2026-08-03

## 방향

책상, 원목, 종이, 필름 같은 물리적 배경을 모두 제거했다. Poly에서 가져온 것은 `한 무대에서 콘텐츠가 흩어지고, 선택되고, 줄어들고, 다시 정렬되는 방식`뿐이다.

맛핀의 무대는 어두운 디지털 콘텐츠 캔버스다.

- 배경: `#0B0C0F`에 가까운 그래파이트 블랙
- 깊이 표현: 아주 약한 그리드, 흐림, 겹침, 크기 차이
- 릴스: 12px 모서리와 1px 경계를 가진 평면 미디어 타일
- 강조색: 전송과 현재 단계에만 사용하는 코랄
- 금지: 네온, 유리, 홀로그램, 과장된 3D, 우주 배경, 가짜 소셜 지표

## 장면

1. `01-scattered.png` — 다크 디지털 캔버스 가장자리에 맛집 릴스가 흩어져 있다.
2. `02-send.png` — 고기 릴스가 선택되고 `matpin.kr로 릴스 보내기` 명령이 나타난다.
3. `03-analyze.png` — 캡션·작성자 댓글·영상 단서를 확인한다.
4. `04-resolve.png` — 약한 정보는 사라지고 역삼동·산장가든·역삼역 4번 출구가 남는다.
5. `05-group.png` — 같은 릴스가 역삼역·성수역·을지로입구역 단위로 정렬된다.
6. `06-station.png` — 역삼역에 저장된 영상 3개가 고정된 결과로 보인다.

## 실제 모션 구현 기준

하나의 `sticky` 캔버스를 유지하고 장면마다 아래 값만 바꾼다.

- 릴스 타일: `translate`, `rotate`, `scale`, `opacity`, `filter: blur()`
- 중앙 UI: 전송창 → 분석 행 → 장소 결과 행 → 역별 그룹
- 하단 단계 표시: 선택된 항목의 코랄 선만 이동
- `prefers-reduced-motion`에서는 각 장면을 즉시 전환하고 모든 보간을 제거

## 생성 방식

Built-in ImageGen을 사용했다. 각 장면에는 직전 맛핀 프레임과 대응하는 Poly 캡처를 레퍼런스로 연결했다. Poly의 로고·사진·문구·고유 에셋은 사용하지 않았다.
