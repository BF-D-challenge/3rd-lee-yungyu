# Matpin × Poly 고유사도 모바일 스토리보드 v2

생성일: 2026-08-03

## 수정 목표

기존의 검은 배경, 네온 외곽선, 유리 카드, 과장된 3D 재질을 제거했다. Poly의 실제 캡처를 이미지 레퍼런스로 연결하고 다음 항목을 기준으로 맛핀의 6장 흐름을 다시 만들었다.

- 위에서 수직으로 내려다보는 고정 카메라
- 따뜻한 원목 작업면과 실제 종이·필름의 물성
- 화면 가장자리에서 자연스럽게 잘리는 많은 콘텐츠
- 중앙의 넓은 여백과 한 번에 하나만 바뀌는 UI
- 작은 반투명 입력창과 하단 고정 단계 표시
- 흩어진 자료가 검색·정리된 결과로 바뀌는 인과관계

Poly의 로고, 문구, 사진, 고유 에셋은 복사하지 않았다. 구조와 연출 문법은 가깝게 맞추고 콘텐츠는 맛핀의 음식 릴스와 역별 보관함으로 교체했다.

## 장면

1. `01-scattered.png` — 음식 릴스가 실제 인화 사진과 필름처럼 작업면 가장자리에 흩어져 있다.
2. `02-send.png` — 중앙 입력창에서 `matpin.kr로 릴스 보내기`를 실행한다.
3. `03-analyze.png` — 고기 릴스 하나를 고정하고 캡션·작성자 댓글·영상 단서를 확인한다.
4. `04-resolve.png` — 약한 단서를 치우고 역삼동·산장가든·역삼역 4번 출구를 남긴다.
5. `05-group.png` — 같은 음식 릴스가 역삼역·성수역·을지로입구역 단위로 정렬된다.
6. `06-station.png` — 역삼역의 저장 영상 3개를 최종 보관함으로 보여준다.

## 구현 기준

실제 구현에서는 배경 전체를 프레임별 이미지로 바꾸지 않는다. 하나의 원목 무대를 고정하고 콘텐츠 오브젝트의 `x/y`, 회전, 크기, 흐림, 투명도만 장면 사이에서 보간한다. 입력창과 하단 단계 표시는 DOM으로 고정해 한국어 텍스트가 항상 선명하고 편집 가능하게 유지한다.

## 생성 방식

Built-in ImageGen을 사용했다. 각 장면에는 직전 맛핀 프레임과 대응하는 Poly 원본 캡처를 함께 레퍼런스로 연결했다.
