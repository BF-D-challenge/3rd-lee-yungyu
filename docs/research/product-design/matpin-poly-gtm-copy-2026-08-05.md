# 맛핀 × Poly GTM 라이팅 전이

확인일: 2026-08-05
참조: [Poly 공식 랜딩](https://poly.app/)

## Poly에서 가져온 구조

1. 제품 범주와 큰 약속을 첫 문장에 둔다.
2. 기능 목록보다 사용자가 얻는 상태를 먼저 말한다.
3. 다음 장면으로 갈수록 `파일 → 파일 내부 장면·페이지·클립`처럼 구체성을 높인다.
4. 짧은 제목 뒤에 제품이 실제로 하는 일을 한 문장으로 증명한다.
5. 처음의 약속을 마지막 행동에서 다시 반복한다.

## 맛핀에서 가져오지 않은 것

- `Intelligent`, `A.I.` 같은 기술 중심 범주명
- 파일 검색·요약·생성처럼 맛핀이 제공하지 않는 기능
- 정확도, 처리 시간, 사용자 수처럼 현재 근거가 없는 증거

| 장면 | 제목 | 보조 문장 | 역할 |
|---|---|---|---|
| 1 | 맛집 릴스가 역별 보관함으로 | Instagram에서 matpin.kr로 보내세요. 릴스 속 장소를 찾아 가까운 역별로 정리해요. | 입력과 결과를 한 번에 약속 |
| 2 | 보낸 릴스를 한곳에서 봐요 | 보내둔 맛집 영상이 화면 하나에 모여요. | 흩어짐과 모임의 대조 |
| 3 | 장소까지 찾아드려요 | 캡션과 작성자 댓글에서 장소를 찾아요. 내 위치는 사용하지 않아요. | 처리 근거와 개인정보 안심 |
| 4 | 가까운 역으로 차곡차곡 | 장소가 여러 곳이면 모두 저장하고, 중복만 한 번으로 정리해요. | 여러 장소·중복 처리 계약 |
| 5 | 역 이름만 알면 바로 다시 봐요 | 역을 고르면 원본 릴스와 장소가 함께 보여요. | 재방문 가치 순간 |
| 6 | 다음 릴스도 보내기만 하세요 | 공유 화면에서 matpin.kr를 선택하면 내 보관함에 이어서 쌓여요. | 첫 약속 반복과 행동 |

## CTA 계약

- 주 CTA: `Instagram에서 시작하기` → Instagram의 matpin.kr 프로필을 새 탭에서 연다.
- 보조 CTA: `저장 흐름 보기` → 같은 화면의 두 번째 장면으로 이동한다.
- 중간 CTA: `다음` → 다음 설명 장면으로 이동한다.
- 건너뛰기: `끝으로` → 마지막 CTA 장면으로 이동한다.

## 라이팅 검사

- 한 문장에 한 메시지
- 기술명보다 사용자 결과 우선
- 제목을 반복하는 빈 보조 문장 없음
- 현재 위치 미사용과 여러 장소 저장을 실제 계약 범위에서만 표현
- CTA가 이동할 채널과 시작 행동을 함께 예고
