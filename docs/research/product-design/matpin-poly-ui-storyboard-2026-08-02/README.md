# 맛핀 Poly 원리 기반 UI 스토리보드

생성일: 2026-08-02
형식: 모바일 세로형 PNG, 6장
목적: 사진 배경 없이 하나의 3D 제품 무대에서 `흩어짐 → 전송 → 분석 → 제거 → 역별 분류 → 보관`의 원인과 결과를 보여준다.

## 공통 시각 원칙

- Poly의 화면을 복제하지 않고, 하나의 무대와 고정 앵커가 스크롤에 따라 변하는 원리만 사용한다.
- 검은 배경, 코발트 블루와 코랄 포인트, 깊이감 있는 릴스 카드와 짧은 이동 흔적을 사용한다.
- 인물 사진, 방 사진, 지도, 휴대전화 프레임, 가짜 좋아요·댓글 수는 사용하지 않는다.
- 랜딩의 긴 제목과 설명은 이미지에 굽지 않고 실제 코드에서 편집 가능한 텍스트로 얹는다.

## 장면별 생성 프롬프트 요약

1. `01-scattered-reels.png` — 음식 릴스 8개가 서로 다른 깊이와 각도로 흩어진 시작 상태.
2. `02-send-to-matpin.png` — 고기 릴스가 고정된 `matpin.kr` 공유 앵커로 이동하는 순간.
3. `03-check-clues.png` — 중심 릴스에서 `캡션`, `작성자 댓글`, `영상 단서`가 연결되어 펼쳐지는 분석 상태.
4. `04-remove-noise.png` — 약한 단서는 사라지고 `역삼동`, `산장가든`, `역삼역 4번 출구`만 남는 정제 상태.
5. `05-group-by-station.png` — 같은 릴스 카드가 `역삼역`, `성수역`, `을지로입구역` 세 그룹으로 이동하는 상태.
6. `06-station-shelf.png` — `역삼역`의 영상 3개가 정렬된 최종 역별 보관함.

## 구현 메모

실제 랜딩에서는 6개 이미지를 단순 교체하기보다 하나의 sticky 무대에서 카드 위치, 회전, 흐림, 투명도, 연결선만 보간한다. 각 장면의 핵심 상태는 고정하고 장면 사이에서만 모션을 발생시키면 모바일에서도 이야기와 성능을 함께 지킬 수 있다.
