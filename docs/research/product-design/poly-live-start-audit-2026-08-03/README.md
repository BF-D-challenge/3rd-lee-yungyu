# Poly 실제 시작 흐름 재확인

확인일: 2026-08-03
확인 URL: https://poly.app/

## 결론

Poly는 흩어진 콘텐츠로 시작하지 않는다. 제품의 약속과 실제 제품 화면이 들어 있는 노트북을 먼저 보여준 다음, 스크롤에 따라 노트북이 분리되고 콘텐츠가 밖으로 터져 나온다. 흩어진 콘텐츠 무대는 다섯 번째 상태다.

## 실제 순서

1. `01-hero.jpg` — 제품 약속, 짧은 설명, 두 행동, 노트북 속 실제 제품 화면.
2. `02-hero-dock.jpg` — 첫 화면은 유지되고 하단 단계 표시가 나타난다.
3. `03-laptop-pivot.jpg` — 주변 환경이 흐려지고 노트북이 무대에서 분리되어 회전한다.
4. `04-content-burst.jpg` — 노트북 속 파일이 화면 밖으로 터져 나온다.
5. `05-scattered-content.jpg` — 콘텐츠가 작업면 가장자리로 안착하고 Discover 설명이 나타난다.

## 맛핀에 적용할 수정 타임라인

1. `제품 약속` — 릴스를 보내면 역별로 정리된다는 약속과 최종 보관함 미리보기.
2. `제품 무대 고정` — 하단 단계 표시가 나타나고 최종 보관함 창에 초점이 맞춰진다.
3. `제품 창 전환` — 보관함 창이 기울고 깊이가 생긴다.
4. `릴스 방출` — 창 안의 맛집 릴스가 디지털 공간으로 나온다.
5. `흩어진 릴스` — 여기서부터 기존 다크 디지털 스토리보드가 이어진다.
6. `보내기 → 단서 확인 → 장소 발견 → 역별 정리 → 역 보관함`.

책상이나 노트북 하드웨어는 복사하지 않는다. Poly의 `약속 → 제품 → 분리 → 방출 → 흩어짐` 인과관계만 다크 디지털 맛핀 무대로 옮긴다.
