## 먼저 읽을 문서

- [SUMMARY.md](SUMMARY.md) — 13개 메뉴별 입력·출력·접근 경계와 제품·콘텐츠·데이터·수익·성장·기술 구조, 재구현 청사진.

- Home부터 Build까지 사이드바 13개 메뉴의 실제 기능·입력·결과·로그인/유료 경계.
- 공개 랜딩, 홈, 아이디어 데이터베이스, 사례 탐색, 인터뷰형 사례, AI researched profile.
- 자연어 `Ask the data`, 전역 검색, 저장·랜덤·Build 연결 구조.
- 가입, 로그인, Starter·Academy 가격, Stripe 결제 진입, 공개·가입·유료 경계.
- HubSpot Media 인수 이후의 포지셔닝과 기존 멤버십 표면의 공존.
- Rails·Heroku·Cloudflare·PostHog·Klaviyo·HubSpot으로 관찰된 기술·운영 구조.

## 한계

- 공개 블랙박스 분석이다. 소스 코드, 서버, 관리자 화면, 결제·권한 우회에는 접근하지 않았다.
- 사용자가 켜 둔 로그인 브라우저는 읽기 전용으로 확인했다. 계정·프로필·결제 설정은 열거나 변경하지 않았다.
- 숫자가 페이지마다 다른 경우 임의로 합치지 않고 각 페이지의 정의와 관찰 시점을 함께 기록했다.
